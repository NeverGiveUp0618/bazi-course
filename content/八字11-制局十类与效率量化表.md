## 一、制局十类：五组对偶，覆盖十神两两相制

中级班「一、正确理解使用各种作用方式」下的完整分类（p1-p6）：

| # | 制局 | 对偶关系 | 常见断象 |
|---|---|---|---|
| （一） | **比劫制财** | 比劫 ↔ 财 | 制得干净→发财；靠合伙求财 |
| （二） | **财制比劫** | 同上反向 | 劫财当财看（换象）；富贵命 |
| （三） | **比劫制官杀** | 比劫 ↔ 官杀 | 制不净的官杀**当财看**→意在发财不在当官 |
| （四） | **官杀制比劫局** | 同上反向 | 管财的大官；官杀制比劫库 |
| （五） | **伤食制官杀** | 食伤 ↔ 官杀 | 显贵掌权 |
| （六） | **官杀制伤食** | 同上反向 | 官制食神结构 |
| （七） | **伤食星制印星** | 食伤 ↔ 印 | 食伤制印，**印主权** |
| （八） | **印星制伤食星** | 同上反向 | 印主权；女命印制伤官**不主权** |
| （九） | **财星制印** | 财 ↔ 印 | **去印得权**，主有官职 |
| （十） | **印星制财** | 同上反向 | **制财得财**，发财的命 |

> 十类正好是**五对十神关系各走两个方向**。记的时候按"谁制谁"两两配对，比死记十条快。

### 高层次命例（原书给的都是顶级样本）

**（四）官杀制比劫局 → 国务院总理**（中级班 p3）

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 乾 | 戊 | 壬 | 癸 | 壬 |
|  | 辰 | 戌 | 巳 | 戌 |

> 命局为火与燥土之势。辰为比劫库，戌为正官也为财库，**两戌冲辰**，月时两壬也被开库的戌自合制之 → **官制比劫结构**（也可理解成财库制比劫库），辰中比劫当财看。天干**戊癸合**为管理、控制之意，戊巳一象，戊透到年上 → 意为**辰中财被自己控制**，此为**管财的大官**。戊辰运，辰出现被制（应期用法）→ 升至国务院总理。

**🔍 拆解：为什么这个盘能到总理级**（我补的推理，非原文，可推翻）

这段原文信息量极大，一句话套一句话。从日主起推：

**第1步·先给每个字定身份**（癸水日主）

| 字 | 是什么 | 双重身份 |
|---|---|---|
| **辰** | 本气戊＝正官 | ⭐ 但更要紧的是：**辰是水库＝癸的比劫库** |
| **戌** | 本气戊＝正官 | ⭐ 同时**戌是火库＝癸的财库** |
| **壬**（月、时） | 劫财 | 两个 |
| **戊**（年干） | 正官 | 与日主**戊癸合** |
| 巳 | 正财 | 戊禄在巳（戊巳一象） |

> ⚠️ **注意四墓库的双重身份**（第7章⑪）：辰戌本气都是戊土（对癸是官），**但作为"库"时，辰是水库、戌是火库**。这个盘的整套逻辑走的是**"库"这条线**，不是本气那条线。

**第2步·主体结构：两个库在打架**

```
   戌（财库）  冲  辰（比劫库）        ← 两戌冲一辰
        ↑                    ↑
     里面装着财          里面装着比劫（＝分我财的人）
```

**"官杀制比劫"是怎么读出来的**：戌的本气是**官**，辰装的是**比劫** → 戌冲辰 ＝ **用官去制比劫**。
原文说也可理解成"**财库制比劫库**"——因为戌又是财库。**两种读法都成立，因为戌本来就一身二职。**

**第3步·为什么"辰中比劫当财看"**

这是最巧的一步：

```
辰里的比劫，本来是"来分我财的人"
        ↓
但它被戌（官/财库）制住了
        ↓
第8章：制住什么，就得到什么
        ↓
被制服的比劫 → 变成"归我调配的人手/资源" → 当财看
```

⭐ 现实对应：**一个能把"竞争者"变成"下属"的人**——这正是"管人"的官。

**第4步·天干那一路：戊癸合＝把控制权抓在手里**

```
戊（正官）—合— 癸（日主）
  ↑
戊禄在巳，而巳在日支 → "戊巳一象"，戊与日主贴身
  ↑
戊又透到年干 → 站到了最高位（年＝远、大、外）

合起来：日主与官星紧密相合，且这个官站得最高
     ＝ 我掌握着这个权力，且级别很高
```

再叠上第2、3步：**辰里的财（被制服的比劫）→ 也在这个戊的掌控范围内** → 原文说的「**辰中财被自己控制**」→ **管财的大官**。

**第5步·为什么层次这么高（用第8章效率表核一遍）**

| 效率指标 | 本命的表现 |
|---|---|
| **作用方式** | **库冲**——效率表里**最高档**（「丑未、辰戌冲库作用最高」「其他冲都赶不上库冲」） |
| **力量对比** | **两戌冲一辰**，且原局是**火与燥土之势**在助戌 → 悬殊 |
| **制得干净吗** | 辰被冲开、辰中比劫被制服；**月时两壬（劫财）也被开库的戌自合制之** → **连带的劫财一起收拾了** |
| **主位参与吗** | ✅ **戊癸合**，日主亲自参与 |
| **归属（第9章）** | 戊透年干、与日主合 → **控制权在我** |

**五项全满 → 顶级。**

> ⭐ **对照着看就明白差在哪了**：本篇 2.3 那个"开出租车"的命（辛丁癸戊／丑酉酉午）——**同样是癸水日主、同样有制**，但用的是**午克酉**（克制＝最低档），且主位没什么参与。
> **同一个日主、同一个"制"的思路，换了作用方式和参与度，一个总理一个出租车司机。**

**第6步·应期为什么在戊辰运**

原局里"辰被制"这件事是**必然要发生的**（第12章：原局定层次）。**戊辰运＝戊到＋辰到**——两个关键字同时到位，"辰被制"这件事的**应期就到了**。

> 💡 这是第12章「**原局的字到大运，就要应与这个字有关的事**」的典型。

**（四）→ 中央政治局委员**（中级班 p3）

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 乾 | 癸 | 丁 | 辛 | 辛 |
|  | 酉 | 巳 | 卯 | 卯 |

> 日时卯财可生巳官，巳克合酉，两卯冲酉，**财官成党，制掉比肩酉金**。酉为日主之禄，**在年上被制不伤日主**。年上癸水无制，因此虽然为制，**但未制尽**。己酉运升到这个级别。

**🔍 拆解：这例专门回答一个矛盾——"禄不是不能制吗？"**（我补的推理，非原文，可推翻）

辛金日主。定角色：**卯＝偏财**（辛克木）｜**巳＝正官**（丙火克辛）｜**酉＝比肩，且是辛的禄**｜癸＝食神。

**第1步·结构：财官联手打比肩**

```
卯（财） ──生──▶ 巳（官）      ← 财生官，两者结成一党
                    ↓
        巳 ──克合──▶ 酉        （巳申…此处为巳克酉，火克金）
        卯 ──冲───▶ 酉        （卯酉冲，两个卯一起冲）
                    ↓
              制掉【酉】（比肩）
                    ↓
第8章制局十类·（四）官杀制比劫：「管理能力强、有主见，多为领导」
```

**第2步·⚠️ 核心矛盾：酉是日主的禄，禄不是"一定不能制"吗？**

第8章禁忌白纸黑字写着：「**日主得了根，其根不能被制**」「**坐支之禄一定不能被制**」。
**这个盘制的正是酉（辛之禄）——为什么没出事，反而当了大官？**

**原文一句话点破**：

> 「酉为日主之禄，**在年上被制不伤日主**」

⭐ **关键在"位置"。** 把禁忌那条原文补全就清楚了（中级班 p5）：

> 「日主**在年月的禄可以被制**，有时候**时支之禄也可以制**，**但坐支之禄及通根一定不能被制**。」

| 禄在哪 | 能不能制 |
|---|---|
| **年、月** | ✅ **可以制** |
| **时支** | 🔶 有时可以 |
| ⭐ **日支（坐支）** | ❌ **绝对不能** |

**本命的酉在【年支】** → 属于"可以制"的那一档。

> 💡 **为什么位置能决定这个？** 我的理解（非原文）：
> **坐支是日主"自己站着的地方"**——那是身体、是命根；
> **年月的禄是"外面的同类"**——更像"分我资源的人"，制掉它反而清爽（比劫被制＝没人分我的了）。
>
> 这也解释了为什么本命制掉酉是好事：**酉在这个盘里的身份是"比肩"（竞争者），不是"我的根"。**

**第3步·"未制尽"为什么反而是层次的天花板**

```
年上【癸】（食神）无人制
        ↓
「虽然为制，但未制尽」
        ↓
   所以是政治局委员，不是更高
```

⭐ 对照同页那个**国务院总理**的盘（戊壬癸壬／辰戌巳戌）：那个是「**月时两壬也被开库的戌自合制之**」——**连带的劫财一起收拾干净了**。

**这就是"制尽"与"未制尽"的差别，也就是两个级别的差别。**

> ⭐ **本例真正要你带走的两条**：
> 1. **禁忌是有位置条件的**——见"制禄"别急着断伤身，**先看禄在哪一柱**
> 2. **同一个字（酉）在不同盘里身份不同**——这里它是"比肩/竞争者"，在别的盘里可能是"我的根"。**先定身份，再套规则。**

**（五）伤食制官杀 → 皇帝（在位八十天）**（中级班 p3）

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 乾 | 己 | 癸 | 丁 | 丁 |
|  | 未 | 酉 | 巳 | 未 |

> 局中比劫与食伤成势，未燥酉、巳克合酉、年上己克癸杀，**杀和杀的原神都处于被制的状态，但没有制净**。
> 行**辰运合绊酉**（酉不再参与原局作用），辰还晦火与燥土 → 此运不仅丢官罢职，几乎被杀（**酉得辰合，正好是辰保护了酉**）。
> **丁卯运的丁运**：丁为日主到，卯冲酉，还在制财官 → **当了皇帝**。
> 但此运的**丙辰年**，辰酉合再次保护酉 → 做皇帝才八十天，便得疾而亡。

> ⭐ 这例把「**保护**」这个机制讲透了：合可以护住被制的字，让制局失效。制局的敌人不只是"制不动"，还有"对方被人护着"。

**🔍 拆解：一生的起落，全系在"酉"一个字上**（我补的推理，非原文，可推翻）

丁火日主。定角色：**酉＝偏财**（丁克金）｜**癸＝七杀**（癸克丁）｜己＝食神｜未＝食神库／木库｜巳＝日主之禄（丁禄在午…此处巳中丙火与丁同党，且巳为丁之旺地）。

> ⚠️ 原文称「制**财官**」「杀和杀的原神」——**酉（财）是癸（杀）的原神**（金生水）。所以这个盘制的是**一条链**：杀 ＋ 生杀的源头。

**第1步·原局：链子已经压住了，但没压死**

```
比劫（丁丁）＋ 食伤（己、未）成势
        ↓
   ┌────────┼────────┐
未燥酉      巳克合酉      己克癸
（燥土脆金）  （六合·克合）  （食神制杀）
        ↓
【酉】被两头夹　【癸】被己克
        ↓
「杀和杀的原神都处于被制的状态」
        ↓
        ⚠️「但没有制净」   ← 全命的伏笔
```

⭐ **"没制净"三个字，是后面所有起落的根源**——**压住了但没压死的东西，随时可能被人扶起来。**

**第2步·辰运：不是"来了坏东西"，是"有人护住了对手"**

```
辰 合 酉（辰酉六合）
     ↓
酉被合住 → 【不再参与原局作用】
     ↓
意思是：那三道压制（未燥、巳克、势）都碰不到它了
     ↓
原文：「酉得辰合，正好是【辰保护了酉】」
     ↓
制局失效 → 丢官罢职，几乎被杀
```

再加一层：**辰是湿土，还"晦火与燥土"**——**连制它的那股势也被削弱了**。
> **一边给对手加保护罩，一边削弱我方火力**——所以这步运才这么惨。

**第3步·丁卯运：把保护罩打掉，立刻登顶**

```
丁 = 日主到位（第12章：原局的字到运，应与该字有关的事）
卯 冲 酉      ← 直接把酉冲开
     ↓
酉重新暴露 → "还在制财官" → 制局恢复
     ↓
   当了皇帝
```

**第4步·丙辰年：保护罩又回来了**

```
丙辰年的【辰】—— 与原局的酉又是【辰酉合】
     ↓
第二次"辰保护酉"
     ↓
制局再度失效 → 在位八十天，得疾而亡
```

⭐ **把三步连起来看，规律一目了然：**

| 时期 | 酉的处境 | 结果 |
|---|---|---|
| 原局 | 被制但没制净 | 底子在 |
| **辰运** | **被辰合住＝有保护** | 丢官、几乎被杀 |
| **丁卯运** | **被卯冲开＝保护没了** | **当皇帝** |
| **丙辰年** | **又被辰合住** | **八十天而亡** |

> ⭐ **一个字的开合，决定一生的起落。** 这就是为什么第9章、第12章反复强调：**断运年，不能只看"来了什么十神"，要看"它对原局那个关键字做了什么"。**
>
> 同一个"辰"，对不懂这套的人只是"湿土、财库"；在这个盘里，**它是对手的保险箱**。

**⚠️ 顺带一条容易忽略的**：合在这里为什么是"保护"而不是"制"？
第7章讲过辰酉合属**助合**（辰土生酉金，酉逢助）——**它不但护住酉，还在给酉加力**。若换成"克合"（如卯戌、巳申），性质就不同了。**看合，先分清是助、是克、是闭气。**

**（八）印星制伤食星 → 财政部长/央行行长**（中级班 p5）

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 乾 | 庚 | 乙 | 癸 | 庚 |
|  | 辰 | 酉 | 卯 | 申 |

> 局中申暗合卯、酉冲卯、辰穿卯，都是印制食伤，**制的非常好**。八字无财，伤食当财看，**印主权**。局中**金纯，制得又干净**，印代表了权力。食为财之源，八字不见财，需抓其源 → 命主是**管银行与财政的官**，曾任财政部长。

**🔍 拆解：三面围攻一个字，所以叫"制得非常好"**（我补的推理，非原文，可推翻）

癸水日主。定角色：**卯＝食神**（癸生木）｜**庚、酉、申、辰＝印**（金生水；辰为湿土生金，同党）｜**无火＝无财**。

**第1步·看清打法：三个字从三个方向打一个卯**

```
        申 ──暗合──▶ 卯      （第7章：卯申暗合，申金制卯木）
        酉 ──冲───▶ 卯      （卯酉冲）
        辰 ──穿───▶ 卯      （卯辰穿，克穿）
                     ↑
              孤零零一个卯
```

⭐ **三种不同的作用方式，同时打同一个目标。** 这就是原文"**制的非常好**"的具体含义——不是某一击特别重，是**没有死角**。

**第2步·为什么强调"金纯"**

「局中**金纯**，制得又干净」——**纯**指的是：

| | 本命 |
|---|---|
| 打人的一方 | 庚、庚、酉、申、辰 —— **全是金土一党，没有杂音** |
| 挨打的一方 | **只有一个卯** |
| 有没有人来护卯 | ❌ 没有（无水生木之外的援手，且癸水日主自己也不生卯——它是被卯泄的一方） |

> 💡 对照【皇帝那例】：那个盘的酉**有辰来合、来护**，所以"没制净"；**这个盘的卯，一个帮手都没有**。
> **"制得干净" = 打得没死角 ＋ 对方没有援军。**

**第3步·制住了食伤，得到的是什么**

这一步是本例最需要转弯的地方：

```
八字【无财】（一个火都没有）
        ↓
第13章：「八字无财星但有伤食星，以伤食当财富看」
        ↓
所以【卯（食神）】＝这个命的财
        ↓
而卯被印三面制住
        ↓
第8章：制住什么，就得到什么
        ↓
   得到了"财"（且是靠印得到的）
        ↓
    印主权 → 用权力去管财
        ↓
   管银行与财政的官
```

⭐ **"管财的官"和"发财的商人"差在哪**：
- 商人：**自己制财、财归自己**（第13章取财方式）
- 本命：**用印（权力）去制"财的源头"** → 他不拥有那些钱，**他管着那些钱**

> 原文「**食为财之源，八字不见财，需抓其源**」正是这个意思——**财本身不在场，他控制的是产生财的那个环节**。这不就是银行/财政的职能吗？

**第4步·用第8章四抓手核一遍层次**

| 抓手 | 本命 |
|---|---|
| **作用方式** | 冲 ＋ 穿 ＋ 暗合，**三种齐上** |
| **制得干净吗** | ✅ 金纯、卯无援 → **干净** |
| **距离** | 申、酉、辰分处年月时，**对日支的卯形成包围** |
| **主位参与吗** | ⚠️ 日主癸水本身不直接打卯，但**卯就坐在日支（主位）** → 打的是"我这儿"的东西，等于我在处置自己的资源 |

**四项接近满分 → 部长级。**

> 💡 **对照本篇 2.3 那个"开出租车"的命**：同样是"制"，那命只有**午克酉**一条线、且午还被丑晦着。
> **一个三面围攻、对方无援；一个单点弱克、自己还带伤。** 这就是部长与出租车司机的差距。

**（九）财星制印 → 法院院长（正厅级）**（中级班 p5）

|  | 年 | 月 | 日 | 时 |

| 乾 | 乙 | 丙 | 甲 | 甲 |

> 两戌夹制制不尽子水，**子未穿是主要作用的力量**。未为比劫羊刃库，也为局中的财星 → 属**财制印**。**去印得权**，主有官职。**比劫羊刃库制印有象** → 职业与公检法有关。

**（十）印星制财 → 海外贸易上千万**（中级班 p6）

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 坤 | 壬 | 丙 | 己 | 辛 |
|  | 子 | 午 | 巳 | 未 |

> 印星巳午火燥土势，午冲子、未穿子，天干丙冲壬、丙辛合制去食神 → 全局意在制年柱壬子财星和其原神辛金。**印星势很强，财势也不太弱，印制财的作用很好**。制财得财 → 发财的命，行癸卯、壬寅运获财上千万，**公司是她一个人的**。

**🔍 拆解：四路人马围攻一柱**（我补的推理，非原文，可推翻）

己土日主。定角色：**壬、子＝财**（己克水）｜**辛＝食神**（己生金）｜**丙、巳、午＝印**｜**未＝比劫**。

**第1步·打的不是一个字，是"一柱＋它的原神"**

```
目标：年柱【壬子】（财） ＋ 时干【辛】（食神＝财的原神，金生水）

四路人马：
  午 ──冲──▶ 子       （地支正冲）
  未 ──穿──▶ 子       （克穿，第7章最重档）
  丙 ──冲──▶ 壬       （天干）
  丙 ──合──▶ 辛       （丙辛合，制去食神＝掐掉财源）
```

⭐ **注意最后一路**：前三路都在打"财"本身，**第四路打的是"生财的那个字"**。

这就是第13章那条财富级别判据：
> 「命局**制财的原神做功**者，为**大富**，一般起步百万级……**制财与财的原神成功者，财富级别会很高**。」

**第2步·为什么强调"财势也不太弱"**

原文：「印星势很强，**财势也不太弱**，印制财的作用很好」——**这句夸的不是"打得狠"，是"对手够格"**。

```
对手太弱 → 制了也没多少收获（打一个没钱的人，抢不到东西）
对手太强 → 制不动（第8章：制不住反被制）
⭐ 对手够强、我更强 → 收获最大
```

> 💡 这与第8章效率四抓手是同一层意思，但换了个角度：**做功的"产出"＝制住的那个东西本身的分量。** 制住一堆废纸和制住一个金库，效率再高也是两回事。

**第3步·为什么"公司是她一个人的"**

这一句最见细节。看**未**：

```
未 是【比劫】（己土的同类）—— 比劫＝合伙人、同辈、分我财的人
        ↓
但未在这个盘里，是【去穿子（财）】的一员 —— 它站在我这边打财
        ↓
比劫没有"分财"，而是"帮我抢财"
        ↓
   财全归我 → 公司是她一个人的
```

⭐ **同一个比劫，站位不同，结果相反**：
- 比劫**去合财、夺财** → 分我的钱（第5章：比劫夺财）
- 比劫**跟我一起制财** → 帮我挣钱，且**不参与分配**

> 💡 对照【题库·题38】那个"合作求财"的命——那里是「**比劫库为朋友，故合作求财**」。**区别在于比劫是"被制"还是"参与制"**：被制／被收进库＝为我所用的人手；参与制＝我的帮手；来合我的财＝抢我钱的人。

**第4步·印制财为什么反而"得财"**

按常理，**印克食伤、财克印**——印和财是对立的。这里却是"印制财"，还发了财。

```
第8章总纲：制住什么，就得到什么
        ↓
用印（我的资源/靠山）把财制住 → 财归我
        ↓
第5章十神组合：「财制印」与「印制财」是一对
   —— 关键看【命局用不用印】
        ↓
此命印成势、是主力 → 用印，所以是"印制财"这个方向
        ↓
   制财得财
```

> ⚠️ 别把这条与第5章的"**财坏印**"搞混：
> | 组合 | 前提 | 结果 |
> |---|---|---|
> | **印制财** | 印是主力、命局用印 | ✅ **制财得财** |
> | **财坏印** | 命局用印，但**财反过来把印打了** | ❌ 没上进心、贪图享受 |
>
> **同样是印与财相碰，谁制住谁，吉凶完全相反。**

|  | 巳 | 丑 | 未 | 午 |

**命例·库冲掌重权**（中级班 p7）

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 乾 | 戊 | 辛 | 丙 | 庚 |
|  | 申 | 酉 | 申 | 寅 |

> 局中金成势，**申寅冲，制寅木印星，制印得权**。**效率很高**，故能掌重权 → 元朝帖木儿丞相（相当于国务院总理）。

**🔍 拆解：库冲两例，一富一贵，差别在制的是什么**（我补的推理，非原文，可推翻）

这两例并排放，最能看清「**做功的效率**」和「**做功的对象**」是两件事。

**【巨富那例】乙己己庚／巳丑未午**（己土日主）

```
势：巳、午（火）＋ 未（燥土）  →  火与燥土成势
靶：月令【丑】
        ↓
    丑未冲（库冲，效率表最高档）
        ↓
丑里装着什么？—— 丑藏【己、癸、辛】
        ├─ 癸 = 己土的【财】（己克水）
        └─ 辛 = 己土的【食神】= 财的原神（土生金、金生水）
        ↓
⭐ 一冲，把【财】和【生财的源头】一起端了
        ↓
第13章：「制财与财的原神成功者，财富级别会很高」
        ↓
       巨富
```

**【丞相那例】戊辛丙庚／申酉申寅**（丙火日主）

```
势：申、酉、申（三个金）→ 金成势
靶：时支【寅】
        ↓
    申寅冲（六冲，「寅申、巳亥冲的作用也很高」）
        ↓
寅是什么？—— 寅藏甲丙戊，甲木 = 丙火的【印】
        ↓
⭐ 制住印
        ↓
第8章制局十类·（七）(八)：印主权 → 制印得权
        ↓
      掌重权（丞相）
```

**并排看，差别一目了然：**

| | 巨富那例 | 丞相那例 |
|---|---|---|
| **效率** | 库冲（最高档） | 六冲（很高） |
| ⭐ **制的是什么** | **财 ＋ 财的原神** | **印** |
| **所以得到** | **钱**（巨富） | **权**（丞相） |

⭐ **一句话：效率决定"多大"，制的对象决定"是什么"。**

```
制财 → 得财 → 富
制印 → 得权 → 贵
制官杀 → 掌权管人
制比劫 → 管团队、财不被分
```

> 💡 **这条能救很多误判**：看到一个高效率的制局，先别急着说"大官"——**得看他制的是哪一类十神**。制财制得再狠，也是商人不是官。

**⚠️ 顺带说清"库冲为什么效率最高"**

对照这两例就明白了：

| | 冲普通地支（如申寅） | 冲库（如丑未） |
|---|---|---|
| 打掉的 | **一个字**（寅，连带藏干） | ⭐ **一整个仓库**——丑里藏着己、癸、辛**三个字** |
| 收获 | 一样东西 | **库里所有东西** |

**库是"打包"的**——冲开一个库，等于一次性拿下里面全部藏干。这就是第8章效率表把"丑未、辰戌冲库"排在最高档的实质原因，也是原文那句「**其他冲的作用都赶不上库冲**」的道理。

### 2.3 克制 —— 最低档

> 「克制就是如戌克亥、子、午克申、酉之类，**克制的作用是比较低的**。一般而言，**要通过克制来作用的只是普通人而已，不会有大的成就**。」
> —— 中级班 p8

**命例**（中级班 p8）：辛丁癸戊／丑酉酉午 → 用财制印的格局，但「**午克酉克制，力小**」，行南方火运 → **开出租车，糊口养家**。

> ⭐ 这条最能解释为什么两个结构相似的八字层次天差地别：**同样是制印，用冲的当丞相，用克的开出租车。**

**🔍 拆解：把"出租车"和"丞相"并排放**（我补的推理，非原文，可推翻）

| | **开出租车** 辛丁癸戊／丑酉酉午 | **元朝丞相** 戊辛丙庚／申酉申寅 |
|---|---|---|
| 日主 | 癸水 | 丙火 |
| 被制的是谁 | **酉**（对癸是偏印） | **寅**（对丙是偏印） |
| **谁去制** | **午**（火） | **申**（金） |
| **用什么方式** | **午克酉** | **申寅冲** |
| 效率档位 | ❌ **克制——最低档** | ✅ **冲——高档** |
| 原文评语 | 「**克制，力小**」 | 「**效率很高**」 |
| 结果 | 糊口养家 | 掌重权 |

**同是"制印得权"，为什么差这么远？三层原因：**

**第1层·方式本身的效率**（第8章效率表）
- **冲**：正面对撞，一次性把对方冲开／冲坏
- **克**：只是五行相克的自然压制，**没有明确的作用通道**——原文说得直白：「要通过**克制**来作用的，**只是普通人而已，不会有大的成就**」

**第2层·打得实不实**
- **丞相**那命：申寅**正面相冲**，且局中**金成势**（三个金助申）→ 力量悬殊、打得实
- **出租车**这命：午克酉，但**午只有一个**，且**丑能晦午火**（第2章：丑是湿土，「丑见午火，晦之更甚」）→ **火自己还被削着**，拿什么去克酉

**第3层·制完得到什么，取决于制得多干净**
两命都是"制印得权"——**印主权**。但**权的大小 ＝ 制的效率**（第13章官运原则1：「**官职的大小看做功的效率如何**」）：
- 制得彻底 → **大权**（丞相）
- 制得勉强 → 只剩一点点"自己说了算"的余地 → **开出租车**（自己是自己的老板，但也仅止于此）

> ⭐ **这一组对照最该记住的**：
> **结构相同 ≠ 层次相同。** 判层次的不是"有没有这个结构"，而是「**用什么方式、打得多实、制得多干净**」。
> 以后看出一个盘"制印得权"，**先别急着说当官**——回效率表查一下他用的是哪一档。

### 2.4 穿制

> 「六穿中，只有**酉戌穿、卯辰穿、子未穿、丑午穿**都可以相制；**申亥穿、寅巳穿相生不能制**。丑午之间也是相生，但因**丑能晦午火**，所以也有相克的意思。**相穿又相克的作用最高**，要想穿制作用，一方必须有很强大的力量制另一方。」
> —— 中级班 p8

**命例·穿制成军官**（中级班 p8）

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 乾 | 乙 | 壬 | 甲 | 甲 |
|  | 未 | 午 | 子 | 戌 |

> 火与燥土成势，主位子水印星无用（无根之木不要水生，喜制之）。年上**未穿制子水**，**未为羊刃库，为军队** → 他是个军官，武警要职、军政委、正师级。

**🔍 拆解：断"军队"的那个字是怎么来的**（我补的推理，非原文，可推翻）

甲木日主（乙壬**甲**甲／未午**子**戌）。

**第1步·先解决那句括号里的话**

> 「主位子水印星**无用**（**无根之木不要水生，喜制之**）」

这一句压着第2章的整条规则链：

```
甲木日主，地支：未、午、子、戌 —— 没有寅卯
        ↓
   无根（未中乙木是库中之木，不作根论）
        ↓
   第2章：活木＝有根 ＋ 有水生，缺一即死木
        ↓
   此命【无根有源】→ 死木
        ↓
   ⭐ 死木忌水（「水多易腐烂、水湿而木不能生火」）
        ↓
   所以坐下的子水（印）不但没用，还是麻烦 → 「喜制之」
```

> 💡 这与本篇【题35 的姊妹例】是同一个判断——**判印能不能制，先判木的死活**。详见 [[实用八字教材/99-命例题库#【题35】⭐ 羊刃库穿印得权（两例）＋一条硬条件|题库·题35]]。

**第2步·"未为羊刃库"是一路推下来的**

```
未 = 木的墓库（亥卯未木局，未为墓）
      ↓
甲木日主 → 木的库 = 【比劫库】
      ↓
比劫的极端形态 = 【羊刃】（甲刃在卯）
      ↓
   所以未 = 羊刃库
      ↓
第7章⑮：羊刃主凶悍、主武、喜制伏
      ↓
   ⭐ 羊刃库 = 一整仓的"武力" = 军队
```

⭐ **这就是"军队"二字的来处**——不是猜的，是**未→木库→比劫库→羊刃库→武**这条链推出来的。

**第3步·合起来**

```
未（羊刃库＝军队）──穿制──▶ 子（印，且是没用的印）
                                ↓
              第8章：制住什么，得到什么；印主权
                                ↓
              用"军队"这个身份掌握了权 → 军官、军政委
```

**第4步·⚠️ 与另一例对照，看"合"如何改变结局**

本篇【题库·题35】命A（乙壬**甲**甲／未午**子**戌）——**就是这个盘**。那里补过一条本页没提的：

> 命A比命B多一个**午未合**，第7章六合的"**闭气**"：「午未合，**未中之木闭气**……闭气则不能流行、不能引拔，**成无用之物，只有逢冲时才可用**」
> → **羊刃库被合住＝刀枪入库** → 是**军政委（不拿枪的武官）**，而不是带兵的。

⭐ **同一个羊刃库，被合住和没被合住，一个政工、一个执法。** 这是判断"武职里具体干哪一行"的抓手。

## 三、⚠️ 穿制有一个反向例外——主位与财星穿

> 「穿的含义**除了有制的意思外，还有一层意思就是不能调和、互不相容、与之为敌**的意思。所以可以穿制印星、穿制官杀星、穿制伤食星，**但主位与财星穿就是表示自己与财没有缘份的意思，不仅无财，反一生不能富**。」
> —— 中级班 p9

**命例**（中级班 p9）

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 坤 | 乙 | 乙 | 丙 | 庚 |
|  | 未 | 酉 | 戌 | 寅 |

> 有火与燥土之势，**主位戌穿制月令酉（财）**。「按制的作用，此造该是发财的命，且应有大财，**但实际却不是，一生未发大财**」——原因就是主位与财星穿＝与财无缘。
> 🔍 **此例已在题库 [[实用八字教材/99-命例题库|【题46】]] 拆解**：穿印／官杀／食伤 ＝ 制住即得到；**唯独穿财是反的**——「日支穿了财，**财与日主无缘了**」。记法：**穿别的得到，穿财失去。**

> ⭐ **这是"按规则推会推错"的典型**，必须单记：
> **穿制印/官杀/食伤 → 成立；主位穿财 → 反而无财。**

## 四、⚠️ 制的禁忌：什么绝对不能制

> 「制的作用中，**日主得了根，其根不能被制，制之则伤寿**。日主在年月的禄可以被制，有的时支之禄可以制，**但坐支的禄一定不能被制**。」
> —— 中级班 p5
> 「理论上什么都可以制，财星可以制，伤食可以制，印可以制，比肩劫财都可以制，**但要注意条件**：
> 其一，有些**主位的得位的星如果要去，可能会伤及六亲**；
> 其二，**连日主根的不能去，去了就坏了，这个人就死了**。」
> —— 中级班 p6

### 不能制的日柱清单（原文照录，p6）

| 类型 | 日柱 | 后果 |
|---|---|---|
| **绝对不能制** | **丁巳、丙午** | — |
| **连根木、连根金** | **乙亥、乙卯、甲寅、甲辰、乙未、庚申、辛酉、丙戌、丁未** | 「**一制就容易伤身体及寿命**」 |
| 例外 | 甲辰被酉合 | 「身体不强，但不会有大问题」 |

**命例·制了通根之火 → 短寿**（中级班 p6）

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 坤 | 壬 | 辛 | 丁 | 辛 |
|  | 子 | 亥 | 巳 | 亥 |

> 丁日主**坐巳为通根**，原局水旺制了火，但**这个火绝对不能制**，丁巳通根，制了人就短寿 → 96年丙子得白血病，**97年丁丑夏天死亡**。

**命例·根被坏 → 突然去世**（中级班 p6）

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 乾 | 癸 | 甲 | 乙 | 庚 |
|  | 丑 | 子 | 未 | 辰 |

> 乙木日主**坐未为坐根**，年上见水生木为活木要生长。**丑未冲、子未穿都把未给坏了**；乙庚合官坐辰也为木的根，行**辛酉运**，**辰酉合坏了木的根，不能活了** → 乙酉年乙酉月得急性肝炎突然去世。**木主肝胆，木根被坏了。**

**🔍 拆解：两例合起来，讲的是同一件事的两种死法**（我补的推理，非原文，可推翻）

**先看第一例（丁巳日）：为什么"绝对不能制"**

```
丁 坐 巳 —— 巳中藏丙戊庚，丙火与丁同党 → 【通根】
        ↓
原局：壬、子、亥、亥 —— 水一大片
        ↓
水旺克火 → 火（连同它的根）被制
        ↓
第8章禁忌：「日主得了根，其根不能被制，制之则伤寿」
        ↓
96丙子（水到位）得白血病 → 97丁丑（丁到、即巳的同党到位，应期）死亡
```

⭐ **注意这不是"身弱"的问题**。若按传统旺衰，会说"丁火身弱、水多为忌"——**但本体系不这么读**，它读的是：**你的根被人打了**。
> 💡 白血病＝血液病。**火主血**（第15章五行病性：火＝心血）——**被制的是火，病就出在血上**。断病的部位，看被打的是哪个五行。

**再看第二例（乙未日）：这个更狠，是"两个根一起断"**

```
乙木有【两个】根：
   ① 日支【未】——未中藏乙，是乙的本根
   ② 时支【辰】——乙庚合，庚官坐辰，辰中也藏乙 → 也是木的根

原局已经在打第①个：
   丑未冲 ＋ 子未穿  →  未被坏
        ↓
   但还剩辰这个根，人还撑得住
        ↓
【辛酉运】：辰酉合 → 把第②个根也合坏了
        ↓
   两个根全断 → 「不能活了」
        ↓
乙酉年乙酉月（酉到位，且乙＝日主到）→ 急性肝炎突然去世
```

⭐ **"突然"二字有讲究**：原局的未早就坏了，人却一直没事——**因为还有辰兜着**。等最后一个根被合掉，**没有过渡，直接崩**。

> 💡 **肝炎＝木主肝胆**（第15章）。同样是"被打的五行决定病位"：
> | 命例 | 被打的 | 病 |
> |---|---|---|
> | 丁巳 | **火** | **血**液病（白血病） |
> | 乙未 | **木** | **肝**胆（急性肝炎） |

**两例的共同结构，可以抽成一条通则：**

```
第1步 找出日主的【全部】根（本气根、藏干根、被合过来的根）
第2步 看它们分别被谁打、打到什么程度
第3步 只要还剩一个完好的根 → 人撑得住（可能只是身体差）
第4步 ⚠️ 最后一个根被断的那一步运 → 就是寿限
```

> ⭐ **这解释了一个常见困惑**：为什么有人原局看着很凶却活得好好的，有人看着还行却突然走了。
> **不看"打了几下"，看"还剩几个根"。**

⚠️ **回到禁忌清单的用法**：那张表（丁巳、丙午、乙亥、乙卯、甲寅、甲辰、乙未、庚申、辛酉、丙戌、丁未）不是让你死记——**它们的共同点是"日主坐在自己的根上"**。见到这些日柱，第一件事是查：**这个根有没有被冲、穿、合、刑**。

## 五、⭐ 「不论旺衰」的唯一明文例外：合财

中级班 p9「四、日主合」：

> 「日主合，要么合财要么合官；日支逢六合，可合财、合官、合伤食，**所合的东西就是日主所追求的**。可否让日主顺利得到想合之物，便要看八字的整体配合了；**如果合的东西坏了，那这个八字就坏了**。」
>
> **提示：合财的时候要看身强身弱。⭐ 只有合财的时候讲身强身弱。**
>
> 1. **身旺财旺** → 合财可**发大财**
> 2. **身弱财旺**，财又无作用 → 合财**肯定是穷人**
> 3. **身旺财虚** → 合财不穷，**有钱花，一般人而已**
> 4. **身弱财虚** → 合财也有财，但不会是大财，**不缺吃喝而已**

> 💡 [[八字08-这套民间八字的特点与断命总纲#特点1 ⭐ 不论旺衰、不取用神忌神——这是整套体系的地基|08 篇特点1]] 说这套体系不论旺衰，十八道法门说旺衰要「活看」。**这里是资料里唯一一处明确写出"什么时候必须看旺衰"的地方**——就是**日主合财**这一种情形。以后遇到日主合财，必须补判身强身弱。

**命例对照**（中级班 p9）

| 命造 | 类型 | 结果 |
|---|---|---|
| 庚丙**壬**丁／子戌申未 | **身旺财旺**，丁壬合财星合身 | **富命**，房地产开发，发财数千万 |
| 甲戊**戊**癸／寅辰子丑 | **身弱合财**（癸坐丑得根算旺），日主无力拿这么重的财 | **一定是穷命**——实际曾有牢狱，一生受穷 |
| 庚庚**庚**乙／子辰午酉 | **身旺合财但财星虚透** | 「不表示富也不表示穷，**只表示有钱花，手头不缺钱**」——八字主要作用不在这里，而在年上子冲制坐支的午（伤官有作用，主技能）→ **书法艺术家** |

> 最后那例还带一条通则：「**八字合财只表示一方面，且还要从别的方面寻找八字的作用，才能不失偏颇。**」

**🔍 拆解：为什么偏偏"合财"这一种要看旺衰**（我补的推理，非原文，可推翻）

**先想清楚"合"是什么动作**

第7章：合＝**占有、得到、亲近、控制**。所以——

```
日主 合 财  =  我伸手去【拿】钱
```

⚠️ **"拿"这个动作，跟别的动作不一样**：

| 动作 | 需不需要"我有多大力气" |
|---|---|
| 我**制**某个字 | 看的是**双方力量对比**（第8章效率表已经在管这件事） |
| 某字**来克我** | 看的是**我的根牢不牢**（第8章禁忌在管） |
| ⭐ **我去合财** | **我要把这东西【搬回家】——搬得动搬不动，取决于我自己的力气 vs 东西的重量** |

**这就是为什么唯独合财要看身强身弱**：**它问的是"你扛得动多少"。**

**四种组合，就是"力气 × 重量"的四种搭配：**

|  | 财旺（东西重） | 财虚（东西轻） |
|---|---|---|
| **身旺**（力气大） | ✅ **发大财**<br>庚丙壬丁／子戌申未 → 房地产数千万 | 🔶 **有钱花而已**<br>庚庚庚乙／子辰午酉 → 书法家 |
| **身弱**（力气小） | ❌ **穷命**<br>甲戊戊癸／寅辰子丑 → 曾有牢狱、一生受穷 | 🔶 **不缺吃喝**<br>（原文第4型） |

⭐ **最惨的是左下角**：**东西又重、我又扛不动** —— 原文说得很重：「日主无力拿得到这么重的财，**所以一定是个穷命**」，实际还应了牢狱。
> 💡 想拿又拿不动，硬要拿 → 出事。这与第13章"财困主"是一回事。

**⚠️ 第三例最值得留意：合财只是"一方面"**

庚庚**庚**乙／子辰午酉 这个命，合财只断出"手头不缺钱"，**真正决定他是谁的不是这个合**：

```
八字的主要作用在：年上【子】冲坐支【午】
                    ↓
              午是伤官，有作用 → 主技能
                    ↓
              书法艺术家
```

原文那句通则说的就是这个：「**八字合财只表示一方面，且还要从别的方面寻找八字的作用**」。

> ⭐ **实战提醒**：看到"日主合财"别停在那儿——
> ① 先按四象限定**财的量级**（这一步要看旺衰）
> ② 再回头找**全局真正的主作用**在哪（这一步不看旺衰，看制与象）
>
> **合财管"有多少钱"，别的作用管"你是干什么的"。** 两件事。

## 八、⭐ 谁制谁：方向不是固定的，看势

> **原问（2026-08-25）**：所有作用关系里都含五行生克。**如果自己是被克的一方，还能不能制？**
> 比如寅申冲，**自己是申**和**自己是寅**，区别有多大？

### 8.1 先破一个直觉：方向不是"谁克谁"定死的

原文列组合时，**双向都写了**：

> **巳申合**：「金水有势 → **申制巳**；木火有势 → **巳制申**」〔中级班 p6，见 2.1〕
> **午亥合**：「火有势 → **制亥**；金水有势 → **制午**」〔同上〕

⭐ 最硬的一条在初中级课里，直接用了"**反克**"二字：

> 「巳申合：① 巳火克申金；② **金水成势时，申反克巳**。」
> 命例：「乙木死木，巳为忌神，**申子辰合水局：巳本克申，但金水成势，申反克巳**。忌神（巳）被制主大吉……**富贵双全（正厅级）**。」
> 〔小任 · 初中级课时笔记17 p4〕

⇒ **被克的一方，只要成势，就能反过来制克它的那一方。**

### 8.2 冲的前提，本来就是比势不是比五行

> 「其作用的条件是**一方之势一定要大于另一方之势**，否则**这些冲都不能作用**。」〔中级班 p7，见 2.2〕

⇒ 寅申冲**不是"申一定赢"**：**谁势大谁赢**；势均力敌，则**谁也制不了谁**（白冲一场，只有动的意思）。

### 8.3 「势」是怎么算的

不是看单个字，是看**地支成不成片**：

> 气势成局第1步：「认势——地支哪几柱构成了『**火与燥土之势／金水之势／水与湿土之势／木火之势**』」
> 〔中级班 p29-31，见 [[八字12-中级班补遗：作用方式16条与干支互通#五、气势成局：断大命的通用套路|12·五]]〕

⇒ 靠**成局、成方、得令、多柱同气**堆出来。

### 8.4 那"我是申"和"我是寅"到底差多少

|  | **我是申**（顺克方） | **我是寅**（被克方） |
| --- | --- | --- |
| **要制成对方** | 门槛低——**金水成势**即可，五行本来就顺 | 门槛高——必须**木火成势**才谈得上反制 |
| **势不够时** | 顶多**冲而不制**（白热闹一场） | ⚠️ 反过来**被申制**，我方受伤 |
| **若那个字是我的根** | — | ⚠️⚠️ 寅若是甲乙日主的**根**，申来冲就不是"能不能制"的问题，而是**坏根**：「日主得了根，其根不能被制，**制之则伤寿**」〔中级班 p5，见第四节〕 |
| **断法上的意义** | 我制对方 ＝ **我得到／掌控它** | 我被制 ＝ **对方得到我／我受累** |

### 8.5 所以判一组作用，按这个顺序问

```
第1问 谁成势？        地支成局／成方／得令／多柱同气 —— 势大的那方才是"制"的一方
        ↓
第2问 在不在主位？    主位参与，效率才高（效率四抓手之一）
        ↓
第3问 那个字是我的根／禄吗？
        是 → 别人来冲就是坏根伤身（不是"我被制"这么简单）
        否 → 才回到"谁制谁"的问题
        ↓
第4问 制得成之后，还有三种破功：
        ① 对手变旺制不动 ② 对手被合保护住 ③ 对手入墓被藏起来
        〔见 [[八字12-中级班补遗：作用方式16条与干支互通#五、气势成局：断大命的通用套路|12·五]]〕
```

> ⭐ **一句话**：**五行生克只定"默认方向"，成势才定"实际方向"**——
> 被克的一方成了势，就能反克回去；而克方若无势，冲了也白冲。
