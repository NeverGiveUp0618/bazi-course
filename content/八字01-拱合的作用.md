# 八字 · 拱合的作用

> [!question] 我的问题（2026-07-31）
> **① 拱合有哪些作用？老师讲没讲？**
> **② 我学习中看到老师讲「申辰拱合出辰中的财」，是什么意思？拱合有这个功能吗？**

> [!tip] 结论
> 讲过，两位老师各讲一层：**小任**讲基础属性，**大任**讲进阶用法。
> 问题②的「拱出辰中之财」出自**大任**，与小任「拱出为虚」**不矛盾**——
> **虚的是拱出的中神，实的是库里被引动的藏干**（见第三节）。

体系：实用八字。**大任**＝原始讲义、命例密集；**小任**＝体系化整理。

## 一、拱合是什么

三合局**去掉中神（帝旺）**，只剩长生 ＋ 墓库的两字。

| 拱合 | 拱出（中神） | 局 |
| :-: | :-: | :-: |
| 申 辰 | 子 | 水 |
| 亥 未 | 卯 | 木 |
| 寅 戌 | 午 | 火 |
| 巳 丑 | 酉 | 金 |

与半合的**铁律**区分：

- **半合**＝**含**中神（申子、子辰、寅午、午戌）
- **拱合**＝**去**中神（申辰、亥未、寅戌、巳丑）
- 「**缺中神（如申辰）不构成半合**」〔小任 · 课时笔记7 p6、17 p6〕

> ⚠️ 大任的资料里「半合」用得较宽（**三合局差一字即称半合局**〔大任 · 03初级班 p31、十八道法门 p33〕），读他的命例时按上下文理解，别硬套小任的严格定义。

## 二、作用总表

|  #  | 作用                                      | 来源  |
| :-: | --------------------------------------- | :-: |
|  1  | 具备「合」的三大属性，但**极重生克**；掌控力与合克性质**比半合更显著** | 小任  |
|  2  | 核心意象「**半路之缘**」——事情未圆满、中途介入、合作不彻底、缘分浅    | 小任  |
|  3  | 拱出的中神是**虚象**，不作实体论、**不增强原局实字力量**        | 小任  |
|  4  | **应期在填实**——大运流年补齐中神，拱合变真三合局，事应于此        | 小任  |
|  5  | 能量排序：三合成局 ＞ 五合/六合 ＞ 半合/拱合               | 小任  |
|  6  | **无「破局」概念**；三合被破后反而拆成半合/拱合来看细节          | 小任  |
|  7  | 三会局**没有**「拱会」「半会」之说                     | 小任  |
|  8  | ⭐ **拱动墓库，引出库中之物**（如财）                   | 大任  |
|  9  | **拱入宫位**——拱到哪个宫，应在哪个宫的人事                | 大任  |
| 10  | 拱出的五行**可直接取象**断职业、财源                    | 大任  |
| 11  | 拱**表示合伙**做事                             | 小任  |
| 12  | 三合、半合、拱局**常用于断婚姻应期**                    | 大任  |
| 13  | 与日支三合、六合、**拱合的字为「副宫」**                  | 大任  |
| 14  | 传统格局：拱禄拱贵、**拱库拱印**、夹禄夹马                 | 大任  |

## 三、⭐ 拱动墓库：引出库中之物

**小任的整理教材里没有这一层，出自大任。**

**乾造**〔大任 · 03初级班 p7〕

|  | 年 | 月 | **日** | 时 |
| :-: | :-: | :-: | :-: | :-: |
| **天干** | 壬 | 癸 | **戊** | 丙 |
| **地支** | 辰 | 卯 | 辰 | 辰 |

> 此造戊土日主坐辰为湿土，帮土力弱，**辰为财库没有开库**，卯辰穿卯木是毛病，戊癸合财看身强弱，局中财重身弱，本日主难以负担重财，局中戊癸合，喜癸水虚透合身，故能有富。走戊运的戊寅年开始转运，**申运就发财了，因申辰拱出辰中之财**。走酉运也发，冲去卯木病神。

**读法**：戊土日主 → 水为财 → **辰＝水库＝财库**。原局三辰，财库满满却「没有开库」，拿不出来。大运走**申**，与原局**辰**成申辰拱（水局），把**辰库中所藏的癸水（正财）引动出来** → 发财。

### 「虚」与「实」是两回事

|  | 是什么 | 性质 |
| --- | --- | --- |
| 拱出的**中神**（子） | 原局根本没有的字 | **虚象**，不能当实神、不能通根；应期在填实 |
| 被拱动的**库中藏干**（辰中癸） | 原局实实在在藏着的 | **实的**，被「拱」这个动作引动出来 |

所以第 3 条（拱出为虚）与第 8 条（拱出库中之财）**指向不同对象，并不打架**。

### 底层依据：拱局与入墓本是一体两读

> 寅、申、巳、亥四大长生点，见其各自的墓库为**入墓**；**子、午、卯、酉见其墓一般不作入墓看，当拱局看**，只有其极弱（无生无助）的情况下，见墓才入。
> 〔大任 · 18地支四墓库 p4–5、十八道法门 p42〕

同样是「申＋辰」，可读成"子入辰墓"，也可读成"申辰拱子"——**取决于组合状态**，这正是第五节判据的来源。

## 四、拱入宫位与其他实战用法

**拱到哪个宫，就应在那个宫代表的人事上**——这是大任最常用的一条，配合第 12、13 两条，断婚姻应期几乎必用。

---

### 命例① 巳丑拱财到妻宫｜癸酉年填实成局而结婚 ⭐

〔大任 · 03初级班 p32〕

|  | 年 | 月 | **日** | 时 |
| :-: | :-: | :-: | :-: | :-: |
| **天干** | 辛 | 丙 | **丁** | 乙 |
| **地支** | 亥 | 申 | 丑 | 巳 |

**原文分析**

> 原局**巳丑拱财局，拱到了妻宫**，癸酉年，**巳酉丑合金局成功**，此年结婚，为**财合到了**。

**这一例演示的是**：拱合的两条主线同时到位——**拱入宫位**（第 9 条）＋ **填实应期**（第 4 条）。是最标准的一个拱合样板。

**拆解**

1. 丁火日主 → **金为财**；男命财也看妻
2. 时支**巳** ＋ 日支**丑** → **巳丑拱酉**（金局去中神），拱出的酉正是财
3. 日支＝**妻宫**，所以是「拱财局**拱到了妻宫**」——财被拱进了老婆的位置
4. 但酉是虚的，**没到就不算数**
5. **癸酉年**补上酉 → **巳酉丑三合金局成功** → 财由虚转实、且合到妻宫 → **该年结婚**

> 💡 对照第 4 条「应期在填实」：这里看得最清楚——原局只是"拱着"，等流年把中神填实那一年，事才发生。

### 命例② 子辰拱入夫宫｜戊辰年结婚

〔大任 · 03初级班 p26〕

|  | 年 | 月 | **日** | 时 |
| :-: | :-: | :-: | :-: | :-: |
| **天干** | 己 | 庚 | **甲** | 癸 |
| **地支** | 酉 | 午 | 子 | 酉 |

**原文分析**

> 女命看婚姻，有正官先看正官，先看**年上酉**，因其坐上己土**甲己有合**，说明酉与自己有关系，所以不看时上的酉。原局甲己合相当于**合住了酉官星**，戊辰年，**辰子拱合了夫宫，拱到了夫位**，甲木日主合己财，己财坐下为夫星，戊辰年**辰酉合住夫星，子辰拱入夫宫**，此年命主结婚。

**这一例演示的是**：**拱入夫宫**定婚期。注意先要解决「两个酉，哪个才是丈夫」——靠**甲己合**把年上酉认成自己的。

**拆解**

1. 甲木日主，女命 → **金为官＝夫**。命中年支酉、时支酉都是官
2. 年上己土与日主**甲己合** → 年柱与我有关系 → **取年上酉为夫星**，时上那个不看
3. 甲己一合，等于**把酉官合住了**
4. **戊辰年**：辰与年支酉**辰酉合** → 合住夫星；同时辰与日支子**子辰拱** → **拱入夫宫**
5. 夫星被合、夫宫被拱，两头都动 → **该年结婚**

> ⚠️ 这里的「子辰」含中神子，按小任的严格定义属**半合**；大任「差一字即称半合局」，行文里也叫"拱"。**读大任的命例时按上下文理解，别硬套小任的定义**（见第一节提醒）。

### 命例③ 寅戌拱火为财｜口才挣钱，做中介

〔大任 · 16实战技巧完整版 p24–25〕

|  | 年 | 月 | **日** | 时 |
| :-: | :-: | :-: | :-: | :-: |
| **天干** | 丁 | 庚 | **癸** | 甲 |
| **地支** | 未 | 戌 | 丑 | 寅 |

大运：辛亥9 · 壬子19 · 癸丑29 · 甲寅39 · 乙卯49

**原文分析**

> 我又说：此人是个生意人吧，做的是**空买空卖**的生意，但一时我想不起是什么行业。他说完全对，**在正规的中介公司做职员**，你是怎么看出的？
> 我说：看**时上甲寅，伤官在时上主口才**，而**寅戌拱火，火为财**，说明是**通过口才而挣钱**的，但**寅空，意为空买空卖之意**，故为**中介**。

**这一例演示的是**：**拱出的五行可直接取象**（第 10 条）。拱出来的字虽虚，但"是什么五行、是什么十神"照样能用来断职业。

**拆解**

1. 癸水日主 → **火为财**。原局天干只有丁火，地支不见巳午
2. 时支**寅** ＋ 月支**戌** → **寅戌拱午**（火局去中神）→ **拱出财**
3. 时上**甲寅**伤官 → 主**口才**
4. 伤官（口才）＋ 拱出的财 → **通过口才挣钱**
5. 关键一笔：**寅落空亡** → 拱出来的财本就虚、寅又空 → **空买空卖** → **中介**

> 💡 这例最能说明「**拱出为虚**」不是缺点而是取象依据——正因为虚，才断出"空买空卖"这种不经手实物的行当。

### 命例④ 拱合表示合伙做事

〔小任 · 38精彩案例剖析3 p1–2〕

|  | 年 | 月 | **日** | 时 |
| :-: | :-: | :-: | :-: | :-: |
| **天干** | 癸 | 壬 | **辛** | 甲 |
| **地支** | 丑 | 辰 | 卯 | 午 |

**原文分析**

> 命主为女性……命主在生活中，**朋友和伙伴多有帮助，尤其在财运上**。然而，亲戚和有血缘关系的人却常骗取其钱财。
> （三）合作关系：**命主多与他人合作求财，拱合关系表示合伙做事**。
> （一）破财原因：命主**财星被合**，易被他人骗取。

**这一例演示的是**：拱合在人事上的象——**合伙**（第 11 条）。与「合＝亲近、结合」一脉相承，落到求财上就是合作、搭伙。

**🔍 拆解：为什么"拱"＝合伙**（我补的推理，非原文，可推翻）

辛金日主（坤造，癸壬**辛**甲／丑辰**卯**午）。**甲、卯＝财**（辛克木）｜癸、壬＝食伤｜丑、辰＝印。

**第1步·哪来的拱**
```
丑（年支）· 辰（月支）——同为湿土，且
午（时支）· 卯（日支）
        ↓
原文取的是【拱合】关系（少中神的虚合，第7章⑤）
```

**第2步·"合伙"这个象是怎么来的**
```
拱 = 两个字【共同】去成就一个不在场的中神
        ↓
   ⭐ 关键在"共同"二字——一件事要两个字合力才办得成
        ↓
   落到人事上 = 两个人搭伙做一件事
        ↓
      合伙
```
> 💡 对照 [[八字11-制局十类与效率量化表]] 那个"合作求财"的命：**比劫库为朋友，故合作求财**——那是靠"比劫"这个十神身份；**本例是靠"拱"这个作用形态**。两条路都能断出合伙。

**第3步·⚠️ 但拱是虚的，所以有代价**
```
拱出的中神是【虚象】（第7章⑤：少中神，当"暗"理解）
        ↓
   合伙这件事本身也带着"不实"的性质
        ↓
   ⭐ 所以同一个盘里既有「朋友伙伴多有帮助」，
      又有「财星被合，易被他人骗取」
```

⭐ **一体两面**：**拱＝要靠别人才成事** → 顺时是助力，逆时就是被人拿捏。
原文那两句（"伙伴多有帮助"＋"常被骗取钱财"）不是矛盾，**是同一个结构的正反面**。

## 五、什么时候拱不成立

三个否决条件，命中任一即不作拱局论：

1. **中神受伤** —— 被破、穿、克，则不作拱局看，**改论入墓**
2. **多而入墓** —— 天干地支合在一起有两个或以上，见各自墓库则入墓。如两个卯木见未，是卯入未墓，**不论卯未拱**〔大任 · 18地支四墓库 p5〕
3. 即便拱成、引出库中之物，仍要看**库开不开**、该五行**是喜是忌**

### 反例：同样戊辰日、同样子辰拱，此命断穷

**坤造**〔大任 · 16实战技巧完整版 p25〕　大运：戌 亥 子 丑

|  | 年 | 月 | **日** | 时 |
| :-: | :-: | :-: | :-: | :-: |
| **天干** | 乙 | 戊 | **戊** | 己 |
| **地支** | 卯 | 子 | 辰 | 未 |

> 分析：**子辰拱局，子为财，拱入日支归自己，好像是有钱的命**，但我们再往细处分析，原局**卯破子**（破的用法），**戊子自合克子**（干支作用），时上**未又穿子**（穿的用法），子水受伤，只能入辰墓了，（**此处为受伤而入墓，不为拱局看了**）而**辰墓又不开**（墓库用法），表示此财不能被自己所有用，**故命穷**。

与第三节那个乾造对照：**同为戊辰日主、同见子辰**，一个发财一个穷——差别全在**中神子有没有受伤、库开不开**。

## 六、老师点名的误区

> 机械套用作用关系：认为"子卯破就不论杀印相生"、"入库就是坏根"、「**拱合直接增强原局**」。
> 正解：需看气机是否贯通、**库是否开、拱是否为虚**。
> 另有一条避坑：**忌将虚拱当实神**。
> 〔小任 · 课时笔记21 p7、整合精修笔记 p172–173〕

## 七、⭐ 补充（2026-08-06 通读中级班后追加）

### 7.1 拱的「意」：少中神 ＝「暗」＝ 非正常方式

中级班在讲各作用方式时，给拱局的提示是一条**取象口径**，本篇原来没收：

> 「因**申辰拱印而少中神**，**拱当作"暗"的意思来理解**……此处申辰拱因**少中神，表示非正常方式**。」
> 〔大任 · 15中级班 p12〕

**命例**（同页）：某坤造申辰拱印局 → 断她「**学习时好偷学或暗中学习**」（因月透的癸印虚，表示外表不爱学）；庚申表夫星，**申辰拱也表示自谈的对象**（非父母介绍的正常渠道）。

> ⭐ 这补上了本篇[[八字01-拱合的作用#二、作用总表|作用总表]]的一层：**拱不只是"虚、力小、半路缘"，它还自带"暗中、非正规、不公开"的象。**
> 断学业 → 偷学；断婚恋 → 自己谈的／私下的；断事 → 走的不是明面渠道。

> 🔍 **这个申辰拱印局的完整拆解**（为什么"拱"能读成"偷学"、"自谈"）见 [[八字12-中级班补遗：作用方式16条与干支互通#其中三条要单独记|12篇·⑤条]]，那里连同"六合优先于暗合"的争夺机制一起讲了。

### 7.2 三合中神双现，改按「入库」论

> 「**三合局：关键看中神，不能被坏，中神双现不为合局，为入库。**」
> 〔大任 · 2012高级面授 p30（红字）〕

本篇[[八字01-拱合的作用#五、什么时候拱不成立|第五节]]记了"什么时候拱不成立"，**但没写不成立之后怎么办**。面授笔记给了下一步：**中神双现 → 不作合局 → 改按入库论**。

**命例**（面授 例69）：辛乙**乙**己／卯未亥卯

> 🔍 **此例已在 [[八字14-2012高级面授笔记：红字结论辑要#三、三合局与闭库（红字）|14篇]] 完整拆解**（禄入墓＝身体差＋单身＋不要丈夫；「乙辛冲不表示开库」的道理）。
> 「三合不成，**中神多而墓之**，卯入未墓。**禄入墓，身体有问题，不结婚，单身，自我封闭。**」
> 附带两条：辛卯之辛不表老公——「是把辛官杀**随卯也带进了墓**，就不要丈夫」；**乙辛冲不表示开库**（天干冲开不了地支的库）。

> 详见 [[八字14-2012高级面授笔记：红字结论辑要#三、三合局与闭库（红字）|14·三]]、[[八字12-中级班补遗：作用方式16条与干支互通#一、各作用方式的「提示」16条（原书逐条给的操作要点）|12·一③⑤]]
