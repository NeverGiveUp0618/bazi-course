# 第7章 · 作用方式总论

> **本章解决什么**：八字里的字**互相发生了什么**——合、冲、刑、穿、破、墓、绝。
> **前置**：[[06-替身系统]]
> **本章定位**：这是**手段**清单。手段是为目的服务的，目的是"**制**"——下一章讲。所以本章要边学边问一句：**这个作用，谁制住了谁？**

## 一·B、⭐⭐ 被漏掉的两种作用：生 和 克（2026-08-28 补）

⚠️ **上面那张总览表里没有"生"和"克"**——因为它们太基本，反而没人当"作用方式"讲。
`十八道法门` 把生、克**排在作用方式的第 1、2 位**〔p30-31〕，而且讲的**根本不是"甲生丙"那么简单**：

### ⭐⭐ 生：生到极处，反而是控制

> 「比如说八字水旺，生了木，木的干支只有一两个，**在这里水真的是生木么？其实水已经控制了木**——古语**水多木漂**就是这个意思。就像大海里浮一根木的时候，**木不仅无生机，还会被水漂来漂去**。」
> 〔十八道法门 p30-31〕

⭐⭐ **更进一步，原文给了两条"五行转化"**：

| 情形 | 转化 |
|---|---|
| **日主为木，其它干支水极旺** | ⭐ 「**日主已经失去了木的本性，而发挥水的性质**……就像洪水发生时，里面的木被洪水带着奔涌冲撞，**已经成了水的助手来破坏其它事物**。这种时候**日主之木也可当水来看，完全可以放弃本五行**」 |
| **日主为木很旺，八字中有点水气却无根无源** | ⭐ 「这点水是一种**附生状态**，**被木泄尽吸收，已经失去了水五行的特性而化为木**」 |

> 「五行在转化后，我们就**不能简单地把水看成水，而是要用木的作用来看**。」

⚠️⚠️ **这条与第3章虚实是两回事，别混**：
```
   虚实  → 问这个字【实不实】（有没有根／生）      ← 判"存在状态"
   转化  → 问这个字【还是不是它自己】（被同化没有） ← 判"五行属性"
```
⭐ **判断顺序**：**先判虚实，再看有没有被极旺的一方同化**。
一个**虚透**的癸水，遇上满盘旺木，就不只是"虚"——它**已经被吸收成木了**。

### ⭐ 克：克是交融，不是消灭

> 「两种五行在相克的时候，**就是它们在交融的时候**。比如金克木，木会被克伤、会失去原五行，**吸收了金气后的木也有了金的特性**——一根树干被削砍成斧头把的时候，再和斧头安在一起，**木已经是助斧头这个金的力量了，它们形成了一体，都以金的特性来发挥作用**。」
> 「当然也有些木在受金克后转化为家具；⭐ **有的活木在受金克后，反而会生长的更好——这里的金已经是助长木的特性了**。」
> 〔十八道法门 p31〕

**其余三条**：
- **水克火**具有**灭火**的功能（真的克没了）
- ⭐ **火克金不能把金克尽，只能改变金的形态**；天干上的火克金可理解为**暖气阳光驱开了寒气云雾、阳光晒化了冰雪**
- ⭐⭐ 总纲：「**五行中有些克是改变形态，有些是彻底克制消灭了对方，这些要仔细辨别。**」

⭐ **"活木受金克反而长得更好"直接印证了第2章**：**活木喜庚金雕琢**（「甲见庚金富寿长」「庚辛之金来劈克，死木也可成栋梁」）。
👉 **所以"被克"不等于"被害"**——**问的是这一克把它变成了什么**，这正是第8章"制"能出层次的道理所在。

## 二、⭐ 16条操作提示（中级班原文，全章最该背的）

中级班给每种作用方式配了一句**提示**，这是密度最高的一段：

| # | 作用 | 提示（原文） |
|---|---|---|
| ① | **天干合** | 要看**被合之字的地支**。日主合年月官星，一般表示**要控制被合之字的地支**。日主合时干时，要看时支——**若时支是禄或比劫，一般不能被坏**（禄和比劫都是"一家人"，一家人要一致对外制财官，被外人制了就不吉） |
| ② | **地支六合** | 要看**有无别的作用方式参与**，然后看**相合之字的天干**（很多时候天干也表示此字的作用） |
| ③ | **三合局** | 关键**看中神的位置**；⚠️ **中神双现不为合局，为入库** |
| ④ | **半合局** | **必须有中神出现**，少一字为半合 |
| ⑤ | **拱局** | 因少中神，**当作"暗"来理解**，表示**非正常方式** |
| ⑥ | **暗合** | 与六合相似，**但力量小于六合**；**暗有不光明之意** |
| ⑦ | **冲** | **相临近冲**、克方力量大于被克方时，**被克方及所含之字易被冲坏** |
| ⑧ | **刑** | **寅巳申三字全见方论（三）刑，寅巳论刑**；丑戌未三字全论刑，**丑戌和未戌也论刑**。刑主刑伤，多指不利六亲 |
| ⑨ | **穿** | 要分清是**生穿还是克穿**；生穿时还有**被生或动**的含义 |
| ⑩ | **破** | **破不表制，只表其破的意思** |
| ⑪ | **墓** | 一般要**结合所墓的十神**来定 |
| ⑫ | **伏吟** | 本意是**移位**——此字表示的人或物有**移动**的象征 |
| ⑬ | 藏干 | 见第6章 |
| ⑭ | 禄 | 见第6章 |
| ⑮ | **羊刃** | **羊为凶，喜制伏**；只有阳干有刃，阴干为劫 |
| ⑯ | **十神** | 一般要**两个或两个以上的组合**，产生新含义 |

〔大任 · 15中级班 p10-16〕

## 三、合：这套体系里最重要的作用

### 3.1 天干五合的四种用法

⚠️ **首先记住一条**：「在实际断命时，**只论合，没有合化之说**。」〔初级班 p19〕

| 用法 | 条件 | 断什么 |
|---|---|---|
| **合制**（合去） | 双方**强弱悬殊**，克方力量大于被克方 | 一方**克去**另一方。被制字若代表人，**此人就死了**；代表事物，**此事就制住了** |
| **合伤** | 一强一弱但**相差不悬殊** | 被伤的字若代表人，**此人身体不好**；代表事物，**此事不顺有问题** |
| **合留** | 流年合住命中之字，该字有气 | **多用于婚姻应期**——把这个人"留住了"，多应人和六亲 |
| **合绊** | **力量相当** | 双方**都失去原性**，只有**逢冲**才能还其原性 |

〔大任 · 03初级班 p19-23〕

> ⚠️ 「此处讲的旺衰**指单柱组合而言**，与传统的旺衰不是一个概念。」——即用**第3章的虚实**来判强弱。

**合绊的三种情形**：①命局中两字紧贴相合 ②八字与大运相合 ③流年与原命局天地合

**命例·合绊使人失去干劲**

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 乾 | 辛 | 丁 | 甲 | 乙 |
|  | 丑 | 酉 | 辰 | 亥 |

> 甲木为活木，活木喜火为秀气、为劳动成果。行**壬辰运**，丁亥年——
> 断：「你交上壬辰运以后，**工作上的干劲明显比以前小多了**，特别是今年基本上**没有什么工作热情，遇事就推推诿诿**。」（对方全部认可）
> 解：原局用丁火，**壬辰运与月柱丁酉天地合绊，无法发挥作用**，所以不想做事情了。
> 而**丙戌年**在工作上还轰轰烈烈干了一场——因**壬丙冲、辰戌冲而解了合绊**之故。
> 〔初级班 p24-23〕

> ⭐ **合绊 → 逢冲解绊**，这一组是应期的常用抓手。

### 3.2 地支六合的四种作用

| 作用 | 哪几组 | 说明 |
|---|---|---|
| **助合** | 辰酉（酉逢助）、寅亥（寅逢助）、午未（未逢助） | 被助方增力，助方**因合而泄，自身作用减弱** |
| **克合** | **卯戌**（戌受克）、**巳申**（申受克） | 一方克倒另一方 |
| **闭气** | 子丑（丑中金闭）、辰酉（辰中水闭）、午未（未中木闭）、卯戌（戌中火闭） | **闭气则不能流行、不能引拔，成无用之物，只有逢冲时才可用** |
| **合伤** | 辰酉（辰中木被酉克伤）、寅亥（寅中火被亥水伤）、巳申（巳中火被申中水伤） | 合的同时伤了藏干 |

〔大任 · 03初级班 p25-26〕

> ⚠️ **同一组六合可能同时属于多类**（如辰酉既助合、又闭气、又合伤）。看断什么事，取哪一层。

面授班还补了一条：

> 「**子丑合、午未合：为闭库，为一个气势。**」〔2012面授 p30〕

### 3.2·B ⭐ 六合的三条总纲与逐组象义（2026-08-28 从十八道法门 p32-33 补）

**三条总纲**（很短，但很重要）：

> ① 「**冲为冲跑，合为合克，暗中相害**」
> ② ⭐ 「一般而言**相冲是冲走反而没事，合中反而容易有大事**」
> ③ ⭐ 「**六合不讲合化**」
> 〔十八道法门 p32〕

⚠️ 第②条是很多人翻车的地方：**见冲就紧张、见合就放心，恰好反了。**
——冲是把它**赶走**，合是把它**扣住并暗中克它**（"合克""暗中相害"）。
⭐ 第③条**与三合对照**：本体系里**只有三合能合化，六合不讲合化**（见 3.2·C）。

**逐组的象义**（本章 3.2 那张表讲的是"作用类型"，这里补的是"这一合像什么"）：

| 合 | 象义〔p32-33〕 |
|---|---|
| **子丑** | 水离不开土、土要水润；⭐ **合的时候有一种"拥抱"的象——丑为金库，一抱起来就把库门关上了 ⇒ 闭金库** |
| **寅亥** | 助木气；**水过旺反使寅变死木**；⭐ **亥中壬会制掉寅中的丙火，所以寅亥合又称「无情之合」** |
| **卯戌** | **戌是财官库时，卯戌合为闭库，凶**；印临死绝地受克时，**卯入戌库会凶死**；⭐ 卯木克戌土 ⇒ **事业上易从事土木工程** |
| **辰酉** | **闭水库**；酉金克去辰中乙木；⭐ **酉金太弱见辰为入墓，会凶死** |
| **午未** | 火生土旺**闭木库**；⭐ **未为财库时走午运＝关闭财库门**——**外边的财进不去，库里的货流不出，"货压在仓库"之象** |
| **巳申** | ⭐ **叫「长生合」，制效率最大**，谁的力量大都可以制倒对方（＝第8章效率表的第一档） |

⭐ **"寅亥＝无情之合"值得单记**：表面上亥生寅、是好事，**实际亥中壬把寅中丙火制掉了**——
👉 这正是第10章象法说的"**同一个组合，看你问的是哪一层**"：论木是助，论火是害。

⚠️ **午未那条是断"财进不来"的现成模型**：库门关上，**不是没财，是财动不了**。

### 3.2·C ⭐⭐ 三合局：中神是"党魁"（2026-08-28 补）

> 「三合局是**长生、帝旺与墓库**三者聚而成的局，也称**党局**，类似于社会关系中的**结党**。其局的主要体现是**有一个目标与核心**——⭐ **我们将中神当作党魁或纲领，其它两神都是佐神**。三合局有一定的亲密性，但**比六合的紧密性差一些**。」
> 〔大任 · 十八道法门 p33〕

⭐ **"党魁 / 佐神"这个比喻很好用**：它一句话解释了为什么**中神一坏全局就散**——
**佐神倒了还有党，党魁倒了就没党了。**

**四条判定规则**〔p33-34〕：

| # | 规则 |
|---|---|
| ① | **杂一个相冲之神在其中、且与所冲之神紧贴 ⇒ 破局**。如亥卯未中杂酉：**酉破卯则木局不成**；杂巳：**巳破亥则三合不成，但半合可成** |
| ② | ⭐ **中神多现或双现，不为合局，以「入墓」论** |
| ③ | ⭐ **三合局是所有合法中，唯一能合化的** |
| ④ | ⭐ **三合没有合绊之说**；⭐ **六合能解三合** |

⚠️ 第④条两句都很实用：
- **三合没有合绊**——所以"合绊"只发生在**六合、天干五合**上（见 3.2 与象法的"合绊"）；
- ⭐ **六合能解三合**——**一个六合就能把一个三合局拆开**。这在断"哪一年局散了"时经常用到。

**半合与拱局的完整清单**〔p33〕：

| | 组 |
|---|---|
| **生地半合** | 亥卯 · 寅午 · 巳酉 · 申子 |
| **墓地半合** | 卯未 · 午戌 · 酉丑 · 子辰 |
| ⭐ **拱局**（缺中神） | **亥未拱木 · 寅戌拱火 · 巳丑拱金 · 申辰拱水** |

> ⭐ **邀合入墓**：「寅午戌三合火，寅为午火的长生之地，**寅死午生，午入戌墓**——就是**寅的路走完了才应凶**，其实是**邀合入墓之象**。故：⭐ **寅木代表谁，谁就应凶出问题。**」〔p34〕
> 👉 与第12章「邀合入墓」那条对照读（12章 八·B ④）。

### 3.2·D ⭐ 夹与拱不是一回事（十二道门法·夹拱门，2026-08-28 补）

本章总览表把"拱局"解作**缺中神的两支 ⇒ 虚象、非正常方式**。
`十二道门法` 第八门专讲夹拱，**给了一个此前没有的层次区分**：

> 「**天干不同为「夹」（次一点），天干同为「拱」（层次好）**。⭐ **这种格局一般不论生克。**
> **拱禄共有五日五时。**⚠️ **与三合局、三会局缺中神，意义上决然不同。**
> **拱禄拱贵、拱库拱印、夹禄夹马**：这里的 ⭐ **贵指贵人，马指正财，库指财库**。」
> 〔大任 · 十八道法门 p49-50 · 第八门「夹拱门」〕

```
   两支中间夹着一个字 ──┬── 两边天干【相同】 ⇒ ⭐ 拱（层次好）
                        └── 两边天干【不同】 ⇒ 夹（次一点）
```

⚠️⚠️ **两条最要紧的提醒**：
1. ⭐ **「一般不论生克」**——这类格局是**看结构**的，别去算谁克谁。
   👉 与第11章那句「**两酉金夹制巳火是制不了的**」正好接上：**夹本来就不是用来"制"的**。
2. ⭐ **「与三合局、三会局缺中神意义上决然不同」**——
   ⚠️ **别把"拱禄拱贵"和"三合缺中神的拱局"当成一回事**：
   ```
      三合缺中神的拱局 → 是【一个局没凑齐】 ⇒ 虚象、非正常方式（总览表那条）
      拱禄拱贵         → 是【一个独立的格】 ⇒ 论层次，不论生克
   ```

**名目里那三个字的定义**（原书点明，容易望文生义）：
| 字 | 指什么 |
|---|---|
| **贵** | **贵人** |
| ⭐ **马** | **正财**（⚠️ **不是驿马**） |
| **库** | **财库** |

> **原书例**：**丙申日 ＋ 戊戌时，夹丁酉，为「连珠夹贵」**。
> 「丙临申子戊当头，富贵似王侯」——⚠️ 但有条件：
> 「凡**丙日干见戊、己出干，多不贵而富**，即使炎上格也如此；⭐ **唯独丙申、丙子日见戊戌时才能大富贵。**」

⚠️ **「拱禄共有五日五时」——原书没有列出是哪五日五时**，本教材不替它补。已记入问题清单待查。

> 〔大任 · 15中级班 p6〕

## 四、冲

### 判据

> 「当**相临近冲**，克方力量大于被克方力量时，**被克方及所含之字易被冲坏**。」〔中级班 p12〕

三个变量：**距离（远近）**、**力量对比**、**顺逆**。

**命例·近冲力大，冲坏月令**

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 坤 | 甲 | 庚 | 庚 | 乙 |

> 「原局金水有势，**子午冲制午火官星**，月令的官星可当父看，故此命**早年死了父亲**。此为**近冲又力量相差大**，故午被冲坏。」〔中级班 p12〕

2. **解合绊**：合绊逢冲还其原性

## 四·B、⭐⭐ 冲的完整判法（2026-08-28 从十八道法门 p36-38 补齐）

> ⚠️ **本章此前讲冲只有一条判据**（近冲＋力量差 ⇒ 冲坏）。
> `十八道法门` 用了整整两页讲冲，**分 A/B/C/D 四段**，是全书对冲最系统的一处。以下按原书顺序补齐。

### ① ⭐⭐ 谁赢：冲神旺衰的三条判据

> 「冲神之旺衰判断：**以多则为旺，寡则为衰；以合局会局为旺，以孤立受克为衰；以得令为旺，以失令为衰。**」
> 〔大任 · 十八道法门 p37〕

| 比什么 | 旺 | 衰 |
|---|---|---|
| **数量** | 多 | 寡 |
| **有没有帮手** | 有合局、会局 | 孤立受克 |
| **月令** | 得令 | 失令 |

### ② ⭐ 这一冲有多重：冲力的两条判据

> 「冲之力强弱判断：**以冲中带克为强，以冲而不克为弱；以大运冲之为强，以太岁冲之为弱。**」〔p37〕

⭐⭐ **①和②是两件事，务必分开**：
```
   ① 三条  →  回答「谁坏谁」（谁是赢的一方）
   ② 两条  →  回答「这一下有多重」（伤害量级）
```
⚠️ 常见错误是拿②去判谁赢——**"大运冲比太岁冲重"说的是力度，不是胜负**。

⚠️ **与第8章"库冲效率最高"不矛盾**，三者各管一层：
```
   开不开得了库  → 看是不是冲库（辰戌丑未之间）
   谁坏谁        → 看①的三条（多／局／令）
   伤得多重      → 看②的两条（带不带克、运还是岁）
```

### ③ ⭐ 六冲逐组的结果（不是"两败俱伤"一句话打发）

> 〔p37 · A 段〕

| 冲 | 结果 |
|---|---|
| **子午** | ⭐ **午被克坏，子则劳累** |
| **卯酉** | ⭐ **卯被克坏，酉则劳累** |
| **寅申** | 以**申金克寅木为主**；⭐ **寅中丙火与申中壬水同时受伤** |
| **巳亥** | 以**亥水克巳火为主**；⭐ **巳中戊土与亥中甲木同时受伤** |
| **辰戌** | **土冲变虚**；辰中乙癸与戌中辛丁同时受伤 |
| **丑未** | **土冲变虚**；丑中癸辛与未中乙丁同时受伤 |

⭐ **两个要点**：
1. **水火金木四冲有明确的主被动**——不是对等互伤。**赢的那方也不是没事，是"劳累"**（子午冲午坏、子累）。
2. **藏干是连坐的**：寅申冲，除本气外**寅丙与申壬一起受伤**——断病、断六亲时这一条经常是关键。

### ④ ⭐ 顺冲与倒冲

> 「相邻力量对等，**主冲方去冲被冲方，即所谓的顺冲**；**被冲方得势，反过来冲主冲方，即是倒冲**。」〔p37〕

⚠️ **"主冲方"是位置概念（谁去冲谁），"得势"是力量概念**——两者不一致时就出现**倒冲**：本该挨打的反过来打人。
👉 这解释了实战中"明明是运来冲命局，结果坏的是大运那个字"的情形。

### ⑤ ⭐⭐ 冲和合撞在一起，听谁的：看位置

> 〔p37 · B 段〕

| 冲神在哪 | 怎么断 | 例（排列） |
|---|---|---|
| 在**两个合神中间** | ⭐ **此合必破，论冲不论合** | 子**午**丑 |
| 在合神**之外但紧邻** | **伤合**——合着自合、冲着自冲，**兼论** | **午**子丑 |
| 在两合**之外相隔、不紧邻** | ⭐ **贪合忘冲，论合不论冲** | 子丑**午** |

⭐ **一句话记法：冲神插在中间就拆散，站在外面就要看远近**——紧邻还能伤合，隔远了就被合"忘"掉了。

### ⑥ ⭐ 近／远、运／岁的分工

> 「**近冲则冲破，隔冲则伤损**；**运冲则冲破冲坏，岁冲则冲动冲开**。**动则为发动，开则为开墓。**」〔p38〕

```
   距离：  近冲 → 冲【破】        隔冲 → 只【伤损】
   来源：  运冲 → 冲【破】冲【坏】  岁冲 → 冲【动】冲【开】
                                    ↑ 动＝发动，开＝开墓
```
⭐ **这条极实用**：同样是冲库，**大运来冲偏"破坏"，流年来冲偏"打开"**——
断"哪一年开库拿到东西"要落在**流年**上，断"哪一步运把它坏了"要落在**大运**上。
👉 与第12章应期直接相接。

### ⑦ ⚠️ 辰戌冲：能制什么、不能制什么

> 「辰戌冲，制去库中之物，水制去火。**辰戌冲，只能制去水、火或木，难以制去金**。如果辛金为毛病，那么冲是制不住的，**只有用未土才能制去辛金，因为内有丁火**。⭐ **记住戌中辛金最难制，往往只会冲出来。**」〔p36〕

```
   辰戌冲 ── 能制 ⇒ 水 / 火 / 木
           └─ 难制 ⇒ 金 ⭐ 尤其【戌中辛金】
                        ↓ 冲只是把它【冲出来】，没制住
                     ⭐ 真要制辛，得用【未】（未中有丁火）
```
⚠️ **这是"冲出来 ≠ 制掉"的最清楚一例**：库开了、东西出来了，**但没人动手打它**——
与本章第五节【题66】那条"冲开库是手段、制到那颗星才是结果"讲的是同一件事。

### ⑧ 丑未冲：合能减力，但冲照旧成立

> 「丑未冲，金克木，水克火，**火土旺时才能制去丑中金水**……**既有丑未冲，又有子丑合的减力，力量减但能冲能合。**」〔p36〕

⭐ **"力量减但能冲能合"**——合只是**削弱**了这一冲，**没有取消它**。
⚠️ 别与⑤里"贪合忘冲"混：那是**位置**决定论哪个；这里是**力度**打了折。

## 五、穿（害）

### ⭐⭐ 先立定位：穿在这套体系里排第几（2026-08-28 补）

`十八道法门` 里关于穿的话散在**五个地方**，拼起来才是完整定位：

> ① 「**盲派断命，主论刑冲合穿破，其中穿最为重要，盲师用的最多。**」〔p40〕
> ② 「**穿的力量大于冲。**」〔p40〕
> ③ 十二地门的次序：「**一合二穿三逢绝，四破五冲六看刑**」〔p48〕
> ④ 「四冲六冲面向面，**相冲不及相穿仇**」〔p49〕
> ⑤ 虚实那一节：「实干怕坏根，**刑穿破怕支神升天**」〔p35〕；动门那一节：「升天入地加伏吟，**刑冲合穿为动门**」〔p44〕

```
   ⭐ 作用方式的权重（十二地门序）：
      合 ＞ 穿 ＞ 绝 ＞ 破 ＞ 冲 ＞ 刑
              ↑ 穿排在冲【前面】，三处原文互证（②③④）
```

⚠️ **这与直觉相反，值得单记**：很多人下意识觉得"冲最狠"，
**本体系恰恰相反——穿比冲重**，因为冲只是力量对撞，穿是**不可调和**（见下）。

⭐ 第⑤条给了穿的两个"岗位"：**坏实干**（与刑、破并列）＋**发动**（与刑、冲、合并列）。

### 本质：不只是"制"，还有"不相容"

> 「穿也为"**制**"的意思。穿有两解释：
> 1、为**穿倒、穿反了**——正的东西可以穿偏，偏的东西可以穿正。"倒"表示**立不住、破坏、消亡、不能调和、排斥、动**的意思
> 2、**主凶灾**——八字中有穿多主凶灾或死亡，看被穿的字代表的六亲是否被穿坏，**穿坏了就有可能死亡**」
> 〔大任 · 17刑冲破害 p2〕

### ⭐ 生穿与克穿要分清

> 「要分清是**生穿还是克穿**，生穿时还有**被生或动**的含义。」〔中级班 p13〕

| 类型 | 哪几组 | 力度 |
|---|---|---|
| **克穿** | 子未、丑午、酉戌、卯辰 | **重**（可以相制） |
| **生穿** | 申亥、寅巳 | **轻**（相生，不能制） |

〔中级班 p8〕

**命例·生穿断出"工作辛苦不称心"**

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 坤 | 丁 | 辛 | 丁 | 戊 |
|  | 巳 | 亥 | 亥 | 申 |

> 「**申亥生穿**，申为财在时表示外边的财要生过来，表示**有工作但不会在本地，要到外边去**（时柱表外地）。申亥穿，申为正财表正式或国家单位，**因一穿正财变偏财**，表示企业了；**申亥穿坐支，非正常而生，表示工作太苦或不称心**。」
> 反馈：某大企驻外地工作人员，**工作辛苦也不称心**。〔中级班 p13〕

### ⚠️⚠️ 库与库相冲：第一功能是「开库」，不是「谁制谁」（2026-08-26 补）

> ⭐ **开库只有两种：冲和刑（⚠️ 不是自刑）。**〔v课 · 第 673、764 讲〕

**辰戌丑未之间的冲，先按"开库"读**，别急着判谁制倒谁：

```
   ❌ 错的问法：辰戌冲，到底是戌制辰还是辰制戌？
        ↓ 这一问会把人带进死胡同
   ✅ 对的问法：
        第1步 冲 ⇒ ⭐ 库开了 ⇒ 库里的东西被引出来
        第2步 引出来之后，⭐ 谁动手打它？—— 这才看制
```

⭐ **【题66】就是被这一问带岔过的**：甲木日主，儿星（辛）在戌中。
```
   辰 戌 冲  ⇒ 开库，把戌中的辛（儿）引出来
   ⭐ 真正动手的是【午】：「午戌合是午中火制戌中金」（效率表原文，见第8章 4.1）
      ＋ 寅生午、三个甲助寅 ⇒ 火力足
        ⇒ 儿星制死 ⇒ 克子女重
```
👉 **同一台机器换个靶子就是【题397】**（寅生午克申 ⇒ 财星制死为大财）——
**印/比劫生食伤，去制某一颗星**；制的是财就发财，制的是官就伤子。

⚠️ **对照**：另有一种情形，**冲本身就是做功**（第8章效率表：丑未·辰戌冲库作用最高）。
**两者不矛盾**：**冲开库是"手段"，制到库里那颗星才是"结果"**——
[[08-制与做功#② ⭐ 官位大小：看做功落在哪一层]] 说的"制到支中之库＝实权"，指的正是**结果那一层**。

### ⭐⭐ 穿的第三种效果：「穿反」——翻转对偶属性（2026-08-26 补齐）

前面讲的是穿的**力度**（克穿重、生穿轻）。**穿还有一种效果不改力度，改的是"性质"**：

> ⭐ **穿会把落在那个字上的【对偶属性】翻一面**：**男 ↔ 女｜大 ↔ 小｜长 ↔ 幼**

**三个独立样本**（方向各不相同，机制一致）：

| 题 | 哪一穿 | 本该是 | 穿完变成 |
|---|---|---|---|
| 【题42】 | 寅巳穿 | 生**儿**（阳） | 生**女**（阴） |
| 【题402】〔v课 712 讲〕 | 子未穿 | 伤**女儿** | 「**被穿就反了，伤儿子了**」 |
| 【题416】〔v课 725 讲〕 | 辰卯穿 | 应**哥哥** | 「**大被穿变小，就是弟弟的问题**」 |

⭐ **操作顺序**：**先按常规定出"本该是什么"，再看有没有穿**——顺序反了就读不出"反"在哪。

⚠️⚠️ **别与"穿偏"混**（两者都归穿名下，但改的东西不同）：

| | 改什么 | 例 |
|---|---|---|
| **穿偏** | ⭐ **程度**（降级） | 【题41】正职降副职 |
| **穿反** | ⭐ **属性**（翻面） | 【题42】【题402】【题416】 |

⚠️ **只有"穿"有翻面效果**。冲、克、绝都是**减损**，不翻面。

### ⚠️ 穿制有一个反向例外

> 「穿的含义除了有制的意思外，还有一层意思就是**不能调和、互不相容、与之为敌**。所以可以穿制印星、穿制官杀星、穿制伤食星，**但主位与财星穿，就是表示自己与财没有缘份的意思——不仅无财，反一生不能富**。」
> 〔大任 · 15中级班 p9〕

**命例**（同页）：乙乙**丙**庚／未酉戌寅
> 有火与燥土之势，**主位戌穿制月令酉（财）**。「按制的作用，此造该是发财的命，且应有大财，**但实际却不是，一生未发大财**。」

> ⭐ **这是"按规则推会推错"的典型**，务必单记：**穿制印/官杀/食伤 → 成立；主位穿财 → 反而无财。**

### ⭐⭐ 穿到底"制不制"、算不算"为我所用"？（2026-08-28 已解决）

**两处原文表面相反**：

| 出处 | 原话 |
|---|---|
| 〔大任 · 17刑冲破害 p2〕 | 「穿**也为"制"的意思**」 |
| 〔大任 · 十八道法门 p40〕 | 「**穿制不了对方，是坏**。冲、合、克都可以制，**唯有穿制不了**，而是一种坏——因为有不可调和的矛盾，有仇，强烈的对抗。」 |

⭐⭐ **但中级班有一句明文列举，直接给了操作口径**：

> 「穿的含义除了有制的意思外，还有一层意思就是**不能调和、互不相容、与之为敌**。所以
> ⭐ **可以穿制印星、穿制官杀星、穿制伤食星**，**但主位与财星穿**，就是表示自己与财没有缘份的意思
> ——**不仅无财，反一生不能富**。」〔大任 · 15中级班 p9〕

```
   ⭐ 六种十神里，穿能制的是：印 · 官杀 · 食伤
                  唯一不能的是：财（主位穿财 ⇒ 反而一生不富）
```

### ⭐ 两道门槛（缺一就不成"制"）

1. ⭐ **必须是克穿**：**酉戌 · 卯辰 · 子未 · 丑午**。**申亥、寅巳是生穿，不能制**（第8章 4.4）
2. **力量要够**：「要想穿制作用，**一方必须有很强大的力量制另一方**」〔中级班 p8〕

**两个穿官杀出功的实证**：
- **【题280】** 酉戌**穿制酉杀** ＋ 壬午自合去印 ⇒ **省政法委书记**
- **【题286】** 行丑运，**丑午穿制杀** ⇒ **升财政局长**

### ⭐⭐ 算不算"为我所用"：原文的判据是决定性的

> 「⭐ **所穿制的字要看对日主是否有用**——如被穿制之字**对日主有用**时，**制之则会伤及身体**。」
> 同页正面那半句：⭐ **「制住了印就是得到了权」**
> 〔大任 · 16实战技巧完整版 p16-17〕

| 被穿的字 | 结果 |
|---|---|
| 对日主**没用**（忌神、压在身上的东西） | ⭐ **制掉＝得到**——"制住了印就是得到了权" |
| 对日主**有用**（命脉） | ⚠️ **制之则伤及身体**——不是得到，是自伤 |

⭐⭐ **【题35】命A/命B是这条最干净的镜像**（同为"未刃库穿子印"）：
```
   死木（无根有源，水对它有害） ⇒ 印可制 ⇒ ⭐ 得权（军政委 / 司法局长）
   活木（有根有源，水是命脉）   ⇒ 印不可制 ⇒ ⚠️ 伤身
```
> 原文自己点破：「如生在未月为木有根，为活木，**不可制印的——制印就伤到了身体。这一点很关键。**」

### ⭐⭐ 两句原文其实不矛盾：穿是"除掉"，不是"取来"

⭐ 十八道法门讲的是**穿的性质**（不可调和的敌对），中级班讲的是**按十神分的操作口径**。
合起来，机制就出来了——⭐ **用第5章的体与用来看，连"财为什么是例外"都解释得通**：

```
   穿 ＝ 敌对关系
        ↓
   对【体】那边的字（印 · 比劫）     ⇒ 敌对有效：理顺自己这边，权归我
   对【压制我】的字（官杀）          ⇒ 敌对有效：制住即掌控
   对【用】——我要占有的东西（财）    ⇒ ⚠️ 自相矛盾
                                       ⭐ 你不可能靠与钱为敌来得到钱
```

⭐⭐ **一句话：穿是"除掉"，不是"取来"。**
**除掉压在你身上的东西，你就得利；但你想要的东西本身，跟它为敌只会离得更远。**
👉 这就是下面那条"主位穿财反而一生不能富"的道理，**不是例外，是同一条规则的必然结果**。

⚠️ **还有一层**：**穿完那个字不是消失，是翻了个面**（穿倒正印当偏印看、穿倒七杀当正官看，见上）。
⭐ 所以穿官杀常见的结果**不是"没官了"，而是官的性质变了**（正变偏、大变小）
——与第8章「**制不净的官杀要当财看**」正好接上。

### ⭐⭐ 穿库开不了库（PDF 原文，为 v课那条补上第二个来源）

> 「**穿库开不了库，只有冲库、刑库才能开。**」〔大任 · 十八道法门 p40〕

⭐ 这一句**独立印证了前面「开库只有两种：冲和刑」**〔v课 · 第 673、764 讲〕——
两个来源、不同年份、说法一致：**一条是听课笔记，一条是 PDF 原文**，这条规则可以放心用。

```
   开库 ✅ 冲库 · 刑库
   开库 ❌ 穿库 · 合库（合是【闭】库，见 3.2）· 自刑
```
⚠️ **穿库不但开不了，还把库里的东西一起坏掉**——与"近刑坏遁藏"（第七节）是一路的。

### ⭐ 六穿里哪一组最狠

> 「⭐ **酉戌穿用的最多，也最为厉害**，金特别旺的时候**酉可以穿倒戌**。寅巳穿、申亥穿，穿带生，力小，只有**穿动、穿倒、不和之象**。」〔p40〕

⚠️ 注意 **"酉穿倒戌"是有条件的：金特别旺**。
——戌是火库、酉是金，常理上戌不怕酉；**金旺到一定程度才反过来穿倒它**。这与④顺冲/倒冲是同一个道理：**位置定不了胜负，力量才定**。

## 六、破

> 「**破不表制，只表其破的意思。**」〔中级班 p13〕

破的含义：**无情、破坏、腐蚀、废弃、破耗财产、漏洞**。

**组数**（本体系口径）：⭐ **只有三组——子卯破、卯午破、午酉破**
——「注：**子与酉之间没有相破的关系**」〔十八道法门 p41〕

> ### ⚠️⚠️ 「四正破」这个称呼容易骗人（2026-08-26 订正一处全站性混用）
>
> 站里常把这三组叫「**四正破**」，因为**它们确实都发生在四正（子午卯酉）之间**。
> ⚠️ **但这个名字会让人以为"四正之间除冲之外的组合都破"，于是把【子酉】也算进去——那是错的。**
>
> ```
>    四正两两组合共 6 组：
>      子午 = 冲          卯酉 = 冲
>      子卯 = 破 ✅       卯午 = 破 ✅       午酉 = 破 ✅
>      ⭐ 子酉 = 【不破】 ← 原文明文否定
> ```
> ⚠️⚠️ **本站一度在四处写成"四正破：子卯·子酉·卯午·午酉"**（把**传统六破**里的"子酉"混了进来），
> **2026-08-26 已全部订正**。
>
> **两套口径对照**（读到"破"先问出自哪套）：
>
> | | 组 | 出处 |
> |---|---|---|
> | ⭐ **本体系** | **子卯·卯午·午酉**（三组） | 〔十八道法门 p41〕 |
> | 传统／盲派六破 | 子酉·丑辰·寅亥·卯午·巳申·未戌 | 〔17刑冲破害 p16〕 |
>
> ⭐ **注意两者的差别不止"含不含巳申"**：
> **传统有「子酉」而本体系否定它；本体系有「子卯」而传统六破里没有。**
> 👉 2026-08-15 全量质检的教训正在此：**用传统六破表去核本站内容，会报出 56 处全是误报的"错"。**

> ### ⭐⭐ 补：这个混用，源头在原书自己（2026-08-28 通读全本后确认）
>
> 上面说"本站一度四处写成含子酉"——**通读 `十八道法门` 全本后发现，原书自身就有三处不一致**：
>
> | 页 | 原书怎么写 |
> |---|---|
> | **p40** 开头 | 列**四组**：「破：子卯破，卯午破，午酉破，**酉子破**」 |
> | **p41** 紧接着 | 缩为**三组**：「午酉相破、酉子相破虽凶，但**在民间命理中不属于相破的范围**」→「**相破有三**：子卯破、卯午破、午酉破」→ ⭐ **明文「注：子与酉之间没有相破的关系」** |
> | **p48** 十二地门序章 | **又把酉子列进去**：「**子卯卯午酉子逢，此为三破不相生**；另有**酉午克性深**，相互为破玄机真」 |
>
> ⭐ **怎么读这三处**：p41 是**带注解的正式口径**（明文否定＋给了替代读法），p40 是**起头列举**，p48 是**歌诀**（歌诀要凑字数，且它把午酉另提为"酉午克性深"）。
> 👉 **以 p41 为准**——这也是本站订正后的口径。**但要知道：这不是抄错，是原书本来就这样。**
>
> ⭐ **子酉的真实口径另有一套**（全书重出三次，都不叫"破"）：
> > 「**酉金不能走子运，走上子运要沉底**，阎王小鬼来勾魂，**不入地狱入牢门**。」
> > 〔十八道法门 **p17** 大运歌、**p41**、**p53** 寿元门〕
>
> ⚠️ **所以"酉见子"确实是凶的**，只是**凶在"死地"这一层，不在"破"这一层**。
> 👉 这解开了题库【题431】的存疑（原文写"酉被寅绝、**子破**、戌穿"）：**那个"破"字应按此条读，不必改成正式的破。**

> ⭐ **破要配合天干看**：
> > 「**郑师讲：地支相破看天干，天干不和相破无祸。**歌诀讲：**天干相合地支破，凶灾猛祸逃不脱**；子卯相破病魔缠，卯午相破血光难。」〔十八道法门 p41〕
>
> ```
>    地支破 ＋ 天干【不和】 ⇒ 无祸   ← 破不一定应事
>    地支破 ＋ 天干【相合】 ⇒ 凶灾猛祸 ⭐ 这才是要命的组合
> ```
> ⚠️ 与第15章「**空亡两字天干合，生有残疾或有伤**」是同一个句式——
> ⭐ **"天干合＋地支坏"是本体系判"生来带残伤"的通用结构**，破、空亡都套这个模子。

> ⚠️ **破基本不做功**：「**相破不做功**，只有**午酉破，午旺却能克酉，也做功**。」〔十八道法门 p41〕

## 七、刑

### ⭐ 口径（已澄清）

| 情形 | 成不成刑 | 力度 |
|---|---|---|
| **寅巳申／丑未戌 三字全** | 成，论「**三刑**」 | **重** |
| **寅巳、丑戌、未戌 两字** | **也算刑** | **程度没那么重** |

〔中级班 p12 原文＋2026-08-07 口径确认〕

> ⚠️ **实战提醒**：见到寅巳两字，**不能因为没凑齐申就当刑不存在**——按轻量的刑读（刑主刑伤、多不利六亲），只是不按三刑的力度断。

### ⚠️ 三刑全了反而不做功

> 「**三刑全了时，三刑不叫做功，是三个字都坏了，功就没有了**，表示的主要是**六亲有问题**。」
> 「看六亲：**宫为主，星为辅，宫星同坏六亲遭殃**。三刑：**刑到哪宫，哪宫六亲有灾**。三刑全**先不论开库，先要论不吉**。」
> 〔大任 · 十八道法门 p38〕

### 巳申相刑其意有三

> ① **相生**：巳乃金之长生、申乃金之禄，**土旺生金**（一支天干透土），此时金旺可刑去寅木
> ② **相克**：在构成寅巳申相刑的基础上，**火旺刑去申金**
> ③ **相合**：**水旺**（一支天干透水），水旺生木；此时**寅不冲申，申也不冲寅**
> 〔大任 · 17刑冲破害 p5〕

> 💡 详细讨论见笔记 [[八字02-申巳的特殊关系]]。

### ⭐⭐ 近刑与远刑：决定是"坏库"还是"开库"（2026-08-28 补）

> 「丑戌未三者为墓库，其相互作用时，**近刑则刑坏墓库中的遁藏，远刑则能开墓库，墓库中之物得以用**。凡财官星临丑戌未墓库，一般都喜刑冲——**近刑则制去为吉，远刑则开墓库为吉**。」
> 〔大任 · 十八道法门 p39〕

```
   ⭐ 同样是刑，距离一变，结果就反过来：
      近刑（贴身） ⇒ 刑【坏】库里的东西 ⇒ 吉在"制去"（忌神被坏掉）
      远刑（隔开） ⇒ 刑【开】墓库       ⇒ 吉在"能用"（喜神被放出来）
```
⚠️ **这条与第四节⑥「近冲则冲破，隔冲则伤损」是同一个思路**：
⭐ **贴身＝下死手，隔开＝只惊动**。刑、冲都遵守这条，是本体系的一个通则。

👉 **实战用法**：局里财官在库中——
**想让它出来用，希望刑得远；想让忌神彻底完蛋，希望刑得近。**

### ⭐ 丑戌未三刑的另外三条

> 〔十八道法门 p39〕

1. **丑与未以六冲为主**，只有**丑戌、未戌以相刑看**；⭐ **丑戌刑、未戌刑也是一种做功方式**
2. ⚠️ **刑会被后来的刑分掉**：「命局中**戌刑丑做功**，大运如再见**未戌刑**，则**戌刑丑的力量减弱，戌制不了丑**」
   ——⭐ **一个戌只能干一件事**；来了第二个对象，原来那份功就散了。这是**大运破坏做功**的一种机制（第8章第八节）。
3. ⭐ **未戌之刑为火，其越刑火越旺**——未戌都藏丁，**互刑反而把火刑旺了**，不是两败俱伤。

### ⭐ 寅巳申：原书说"以相穿论之"

> 「寅巳申三刑：此三刑**以寅巳刑为主，命局以相穿论之**，寅刑巳还可以冲论，**二者近则坏，远则动**。巳申以相合为主，寅申以六冲来论。」
> 〔大任 · 十八道法门 p38〕

⭐ **拆开看，寅巳申其实是三种作用各管一边**：
```
   寅—巳 ⇒ ⭐ 按【穿】读（原书原话："命局以相穿论之"）
   巳—申 ⇒ 按【合】读
   寅—申 ⇒ 按【冲】读
        ↓ 三者同时出现时，"刑"的意思才显出来
```
⚠️ 与本节开头「寅巳两字也算刑」不冲突：**寅巳的作用本体是穿，"刑"是三字凑齐后附加的一层。**
👉 这也回头印证了第五节把**寅巳列为生穿**——同一组关系，两处原文都当穿看。

### 绝

**四绝**：**子巳、午亥、卯申、寅酉**——「缘分短」
> 「寅酉相绝见血光，卯申绝合路途伤；四绝：子巳情谊断，寅酉穿血衣，卯申路途死，午亥生闷气。」〔十八道法门 p43〕

### 自合 ⭐

> 「自合是**合而制之，属做功方式**，**没有合绊的意思**。」「自合是**能做功的一种方式**，是合的一种，**合则能去**。」
> 〔十八道法门 p35〕

> ⭐ 自合很容易被忽略，但它**能做功**。前面第3章那个"癸巳自合"发财的例子就是。

**八柱与助记口诀**〔十八道法门 p35〕：

> **丁亥　己亥　辛巳　癸巳　壬午　甲午　戊子　丙戌**
> ⭐ **口诀：「害死伍子胥」**（谐音记这八柱）

**四条使用规则**（同页，此前本章只收了"合而制之"那一条）：
1. ⚠️ **自合柱的支若被它支冲，则干支不能自合**——⭐ **冲能破自合**
2. ⭐ **前四柱（丁亥、己亥、辛巳、癸巳）地支能合克天干**
3. **丙戌柱的自合做功比较少见**
4. **自合干支依据力量大小可反制**——不是天干一定制地支

> ⚠️ **附则（不属于自合，别混）**：「**戌逢未刑时开库**；逢丑刑（金水强时）则可坏戌中遁藏之物，**不属于自合范畴**。」
> 另有两组是**刑开库之后才成立的合**：**丙戌**（戌逢未刑时，丙能合戌中辛）、**壬戌**（戌逢未刑时，壬能合戌中丁）。
> ⭐ 这两组的前提是**先刑开库**——与本章第七节"远刑则开墓库"接得上。

### ⭐⭐ 自合其实是九柱：另一本专著把「壬戌」也算了进来（2026-08-28 补）

`21干支互通`（＝大任老资料里那个 `六爻.pdf`，同一文件）**专讲干支怎么作用**，
它把自合列在「**天干与地支是相合的关系**」这一节，**给的是九柱**：

> 「在八字体系中，⭐ **天干可以克地支，而地支是不可以克天干的**。
> 地支如果想克天干是**有条件制约的**——⭐ **只有在天干与地支相合的情况下，地支才可以克天干。**
> 在六十个单柱中：只有 **甲午、丙戌（戌要开库时）、丁亥、戊子、己亥、辛巳、壬午、壬戌（戌要开库时）、癸巳**，
> 共**九个**天干与地支相合的单柱。其中，⭐ **丁亥、己亥、辛巳、癸巳，可以是地支克天干**，别的柱也各有其意。」
> 〔大任 · **21干支互通** p8-9〕

**与十八道法门 p35 的八柱对照**：

| | 柱 |
|---|---|
| 〔十八道法门 p35〕 | 丁亥 己亥 辛巳 癸巳 壬午 甲午 戊子 **丙戌**（八柱，口诀"害死伍子胥"） |
| ⭐〔21干支互通 p8〕 | 同上八柱 ＋ ⭐ **壬戌**，并给**丙戌、壬戌**加了条件「**戌要开库时**」 |

⭐⭐ **两处其实不冲突，是详略之别**：十八道法门把**壬戌**放在附则里
（「戌逢未刑时，壬能合戌中丁」），`21干支互通` 直接把它**列进正表**并写明条件。
👉 **实战按九柱记，但丙戌、壬戌要挂一个前提：戌得先开库（未刑／丑刑）。**

### ⭐ 一条更根本的规则：地支本来克不了天干

上面那段的**第一句才是纲**：
```
   ⭐ 天干【可以】克地支
   ⭐ 地支【不可以】克天干
        ↓ 唯一的例外
   ⭐⭐ 只有干支【相合】时，地支才可以克天干
        ↓ 而且只有这四柱做得到
      丁亥 · 己亥 · 辛巳 · 癸巳
```
⚠️ **这四柱正是十八道法门说的"前四柱地支能合克天干"**〔p35〕——**两本原文完全对得上**，
可以放心用。
⭐ **意义**：自合之所以是"做功方式"，根子在这里——**它是地支唯一能反过来制天干的通道**。

### 伏吟

> 「**伏吟本意是表示移位**，当命中有伏吟字出现时，此字表示的**人或物有移动的象征**。」〔中级班 p14〕

**命例·伏吟断出搬家四次**

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 乾 | 戊 | 甲 | 丙 | 庚 |
|  | 戌 | 寅 | 寅 | 寅 |

> 「命中**寅木三个伏吟**，表示寅木代表的人或物要**移位**。此命中寅木**印星可作房子看**，故断他**要移家，且要移四次**。」
> 丙戌年命主来测时，正是关心又买了一块地皮盖房用，**且正好是第四个家**。又断他是**由村中间逐步向外移**，且原来住的是**楼房**——全对。
> （月令看祖业，甲也是房，**房上见房是楼房**；月令看中间，由月移向时，**时柱表外边**）〔中级班 p14〕

### ⭐ 伏吟的第二个用法：整柱可换（2026-08-18 补）

"移位"是说**事**在动；同一个规则换个角度看，说的是**位置可以互换**：

> **某天干在两处伏吟，这两处所坐的支都归这个干管——两柱可以互相当着看。**

> 「**甲甲伏吟，甲寅中的寅当婚姻宫看，那么甲辰的辰也可以当婚姻宫看了。**」〔老师口授 2026-08-18〕

- 用在**日干**上 ⇒ 得**第二个婚姻宫**（第14章副宫来源④、【题11】）
- 用在表**六亲的干**上 ⇒ 那个六亲的信息在两柱上一起读（【题181】乙伏吟，丑酉都作母的下肢看）
- 用在**整柱伏吟**上 ⇒ 两柱表同一个人（【题186】年柱甲寅伏吟到时柱，都表爷爷）

⚠️ 与"移位"不冲突：**移位是同一样东西换了地方，所以两个地方都算它的。**

## 八·B、⭐⭐ 倒象：又生又克、与原意相违背（2026-08-26 新增）

> ⚠️ **这一节是全书此前完全没有的一个概念**，来自**大老师v课**（第 672–765 讲反复讲、第 691 讲给定义、第 737 讲分型）。
> **它不是第九种作用方式**，而是**作用方式之间的一种矛盾状态**——所以放在本章末尾，等你把前八节都认得了再看。
> 完整讲解见 [[八字20-倒象是什么]]。

### 定义

> 「**倒象：就是与原有的意思相违背，三心二意的。**」〔v课 · 第 691 讲〕

> ⭐ **原局"倒象"会破坏格局；大运流年"倒象"，运气就不会好。**
> **倒象就是倒霉。看倒象的字代表什么含义，就应在哪些方面。**〔v课 · 第 691 讲〕
> ⭐ **流年倒象最为凶。**〔v课 · 第 746 讲〕

**一句话**：**你派去做这件事的字，同时又在拆这件事的台。**

### ⭐ 三种形态（第 737 讲分的型，第三型是归纳的）

| 型 | 形态 | 怎么认 | 样本 |
|---|---|---|---|
| **① 又生又克** | 同一个字，一边在制它、一边在养它 | 顺着生克链走一遍，看有没有绕回来 | 【题391】【题376】【题427】【题424】 |
| **② 与忌神同柱** | **该被制的忌神，和我派去制它的字成了一家** | 盘面上**没有生的动作**，全靠"同柱＝一家" | ⭐【题429】 |
| **③ 合冲同打一片** | 对同一片五行**又合又冲**（又拉又推） | 天干地支分头看 | 【题414】 |

**第②型最难认**，因为它不表现为任何一条生克线：

> 「**戊土不喜生，财制印为好；亥子都去制午，为好。但是丁亥同柱为一家**（**不用看自合**），
> **怎么又和坏人一家了？所以这也是倒象，和忌神同柱的原因。**」〔v课 · 第 737 讲〕

⭐ **同柱就算一家，自合与否不影响**。老师还给了一个**运里成家**的例子：
> 「**己未日，月柱有丑，丑未冲，印库制官杀库；但是大运或者流年出现辛卯，就是倒象**——
> **辛就是丑，卯就是未**，本来是冲制的关系，**辛卯成一家了**。」〔v课 · 第 737 讲〕

### ⚠️ 虚实决定倒象的轻重

> 「**好就好在这个丙是丙子，虚透的火，甲没办法真正去生**。如果是**丙午**一柱……
> **甲不去制辰，就管不了人了，要出问题了**。」〔v课 · 第 672 讲〕

```
   拆台的那条线，走的是【虚透之干】 ⇒ 轻度 ⇒ 只降格局
   走的是【通根之字】             ⇒ 重度 ⇒ 主线直接断掉
```

### ⚠️ 程度：够不上倒象但要扣分

> 学员问：「甲克戊，戊做辰，甲辰也是一家，是不是倒象了？」
> 答：「**不算倒象，但是有倒象的意思**——卯辰穿，卯可以借象甲，甲又坐辰为一家，**自己穿自己**。」
> 〔v课 · 第 764 讲〕

⭐ **倒象是连续的，不是有/无两档**。判到"有倒象的意思"就该在层次上扣一分，不必非要坐实。

### 实战三步

```
第1步  先把这个盘的【主线做功】找出来（谁制谁，靠它成事）
        ↓
第2步  顺着那个"动手的字"往下走一遍生克链——
        ⭐ 看它有没有绕回去养对手 / 有没有和对手同柱
        ↓
第3步  绕回来了 ⇒ 倒象
        ⭐ 落到哪件事上？—— 看【倒象的那个字】代表什么
             代表官 ⇒ 官做不成｜代表财 ⇒ 财发不了｜代表夫 ⇒ 婚办不成
```

⚠️ **别把倒象当成"生克抵消"来算力量**。它不是加减法，是**性质判断**——
一旦成立，那件事就带上"三心二意、办不成、反复"的性质，**跟双方力量大小无关**。

### 与既有概念的分界

| 容易混的 | 分界 |
|---|---|
| **既制又用主凶灾**（【题36】【题50】） | 那是"**我又要用它又要制它**"；倒象是"**我一边制它一边养它**" |
| **不服制**（【题78】【题82】【题83】） | 那是"**被制的字被第三方扶起来**"；倒象的矛盾**出在我自己这一边** |
| **合绊** | 合绊是**动不了**；倒象是**动了，但两个方向** |

## 八·C、⭐ 作用方式清单的最后三项：患 · 调候 · 关财门（2026-08-28 补）

`十八道法门 p44` 收尾时列了作用方式的**完整清单**：
> 「生、克、五合、六合、三合、暗合、干支自合、干支虚实、冲、刑、穿破、墓、绝、**患**、**调候**、**关财门**、禄与原身」

⚠️ **最后三项本章此前没有**（本章总览表也没列）。原文各只有一两句，但都是**能直接定事的**：

### ⭐ 患

> 「**患夫患妻，重配重娶；患父患母，必克父母。**」〔p43〕

⭐ **"患"是一个独立的作用方式**，断的是**六亲的重复与损伤**：
```
   患【夫】/ 患【妻】  ⇒ 重配、重娶（⭐ 不止一次婚）
   患【父】/ 患【母】  ⇒ 必克父母
```
⚠️ **注意它与第14章"数宫/数星"两套计数法是并行的另一条线索**——
见到"患"的结构，**婚姻次数这条要往"不止一次"上想**。
👉 v课带进来的「**互患空亡**」（第15章 3.1·C）用的正是这个"患"字，
⭐ **两处合起来看："患"是"成双出问题"的意思。**

### ⭐ 调候

> 「**大雪后、雨水前**出生的金、木、水、土都称**寒木、寒金、寒土、寒水**，此时就要**用火来调候**。」〔p43〕

```
   ⭐ 调候的节气区间：【大雪】 ──────────▶ 【雨水】
                       （子月中）      （寅月中）
                    横跨 子 · 丑 · 寅 三个月
        ↓
   生在这段里的 金/木/水/土 ⇒ 寒金/寒木/寒水/寒土 ⇒ ⭐ 要用【火】
```
⚠️ ⭐ **这是节气区间，不是"冬三月"**——**起点在大雪（不是立冬），终点在雨水（已进寅月）**。
👉 与第2章「**庚生冬天为寒金，急需用火来暖身；庚生子丑不见火，直断此命早丧身**」是同一条的两处落点；
也解释了第2章甲木「**冬木要有根，无根无寿**」为什么还要看有没有火。

⚠️ **调候不推翻"不取用神"的立场**：它是**针对"寒"这一件事**的处理，属第1章说的**活论用神**——
**看寒暖就有寒暖的参照，不是给全局定一个用神。**

### ⭐ 关财门（补男命那一半）

> 「**女命关财门者伤夫或离婚，男命关财门者破财或伤灾。**」〔p43〕

| | 关财门应什么 |
|---|---|
| **女命** | ⭐ **伤夫或离婚**（财是"情缘线"，财门一关，官星失养）——第14章已收 |
| **男命** | ⭐ **破财或伤灾**（补）——⚠️ **不是应婚姻，是应财与灾** |

⚠️⚠️ **同一个结构，男女应的事完全不同**，别把女命那套套到男命头上。
⭐ 女命走的是**「无财不养官」**这条链（第14章 七·B ⑦）；男命的财就是**财本身**，关了就是破财。

## 十、自测

**第1题**｜某命大运与月柱天地合绊。这一步运会怎样？什么时候能解？

**第2题**｜寅巳两字相见，但命中无申。论不论刑？

**第3题**｜下面这个断法错在哪？
> 「他主位（日支）戌土穿制月令酉财，制住了财，所以是发财的命。」

**第4题**｜某命申亥穿，申为财在时柱。断什么？

**第5题（较难）**｜同样是"合"，为什么有的合能做功、有的合反而让人失去干劲？

---

### 答案

**第1题**：**这一步运里，被绊的那个字失去作用**。
> 「凡合绊双方**都失去原性，只有逢冲时才能还其原性**。」〔初级班 p22〕
参考命例：辛丁甲乙／丑酉辰亥，壬辰运与月柱丁酉天地合绊，原局用的丁火发挥不出来 → **工作没干劲、推诿**。到**丙戌年壬丙冲、辰戌冲解绊**，当年就轰轰烈烈干了一场。
所以：**逢冲之年解绊**。

**第2题**：**论刑，但程度轻。**
> 「**寅巳申要三字全见方论刑，寅巳论刑**」〔中级班 p12〕
口径：三字全＝「三刑」力量重；两字＝也成刑，**程度没那么重**。
⚠️ 不能因为没凑齐申就当刑不存在。

**第3题**：错在**触犯了穿制的反向例外**。
> 「可以穿制印星、穿制官杀星、穿制伤食星，**但主位与财星穿，就是表示自己与财没有缘份的意思——不仅无财，反一生不能富**。」〔中级班 p9〕
原书那个命（乙乙丙庚／未酉戌寅）正是"按制的作用该发大财，**实际一生未发**"。

**第4题**：**有工作但不在本地，且工作辛苦、不称心。**
> 申亥是**生穿**（轻），申在**时柱**（表外地/门户），一穿**正财变偏财**（正式单位变企业），**坐支非正常而生 → 工作太苦或不称心**。〔中级班 p13〕
实际反馈：某大企**驻外地**工作人员，工作辛苦也不称心。

**第5题**：因为**合有四种用法，结果完全不同**。

| 情形 | 结果 |
|---|---|
| **合制**（强弱悬殊） | 一方制去另一方 → **能做功** |
| **自合** | 「合而制之」→ **能做功** |
| **合绊**（力量相当） | **双方都失去原性** → 不但不做功，还让原来能用的字**用不了** |

那个"没干劲"的命，原局**用**丁火，结果大运把丁火**绊住**了——不是丁火被制掉，而是**被冻结**。
⭐ 判断关键仍是**力量对比**（用第3章虚实判）：悬殊则制，相当则绊。
