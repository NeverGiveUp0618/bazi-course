# 八字 · 申巳（巳申）的特殊关系

> [!question] 我的问题（2026-07-31）
> **① 申巳有啥特殊关系？**
> **② 为啥有时候又有生的关系了？**

> [!tip] 结论
> 申巳这一组地支身上**叠了四种关系**：合、刑、破、生——所以看着才乱。
> 默认按**六合**论；**三字全才论「三刑」，但两字也成刑，只是程度轻**（见第一节表下注）；**破**属另一套口径。
> 至于「生」，来路有两条：
> **结构上**——巳是庚金的**长生**、申是庚金的**禄**，两支藏干还共有庚、戊，金气本来就通；
> **条件上**——天干透土（戊/己）即成「**土旺生金**」，此时论生不论克。
> 大任把这层专门讲成「**巳申相刑，其意有三**：相生／相克／相合」，见第四节。

体系：实用八字。**大任**＝原始讲义、命例密集；**小任**＝体系化整理。
下文每条标来源，格式 `〔大任 · 文件 pN〕`，文件全名见文末。

## 一、一组地支，叠了四种关系

| 关系 | 何时论 | 主要出处 |
| :-: | --- | :-: |
| **合**（六合） | **默认**。「一般来说寅申为冲，**巳申为合**，只有寅巳才论刑」 | 大任 · 十八道法门 p38 |
| **刑** | **寅巳申三字全见**才论**三刑**；即便成刑，「巳与申仍**以六合为主**，刑只是一种附带作用」 | 大任 · 03初级班 p36 |
| **生** | 巳＝金之长生、申＝金之禄；**天干透土**则土旺生金 | 大任 · 17刑冲破害 p5 |
| **破** | 传统／盲派六破里有「巳申相破」，**本体系主口径的四正破不含它** | 大任 · 17刑冲破害 p16、p20 |

> 这就是"看着矛盾"的根源：**同一组巳申，条件不同，读法完全不同**。

> [!important] ⭐ 刑的口径已澄清（2026-08-07）
> 中级班 p12 的原文是：「**寅巳申要三字全见方论刑，寅巳论刑**；丑戌未三字全论刑，**丑戌和未戌也论刑**。」
> 表面上与本表「三字全才论刑」冲突，**我当时标了存疑**。
> **已确认的口径（用户裁定）**：
> - **三字全 → 成「三刑」，力量重**
> - **两字（寅巳、丑戌、未戌）→ 也算刑，但程度没那么重**
>
> 所以本表「三字全才论刑」应读作「**三字全才论"三刑"**」——两字并非不成刑，只是**轻**。
> 实战含义：见到寅巳两字，**不能因为没凑齐申就当刑不存在**，要按轻量的刑去读（刑主刑伤、多不利六亲），只是不必按三刑的力度断。
> 参见 [[八字12-中级班补遗：作用方式16条与干支互通#一、各作用方式的「提示」16条（原书逐条给的操作要点）|12·一⑧]]

## 二、「生」的底子：藏干与长生

### 藏干共有庚、戊

| 地支 | 本气 | 中气 | 余气 |
| :-: | :-: | :-: | :-: |
| **巳** | 丙 火 | **庚 金** | **戊 土** |
| **申** | **庚 金** | 壬 水 | **戊 土** |

两支**共有庚金与戊土**——金气本来就是通着的，这是能论"生"的结构基础。

### 十二长生上是「长生 → 禄」

> **巳乃金之长生，申乃金之禄**〔大任 · 17刑冲破害 p5〕

对庚金而言，巳是起点、申是当旺处，两者本就是同一条金气的**首尾**。所以这个六合另有专名——

> **(6)巳申合：叫「长生合」**，制效率最大，谁的力量大都可以制倒对方
> 〔大任 · 十八道法门 p33〕

**「长生合」这个名字，本身就点明了它带生意。**

## 三、巳申合：效率最高，谁力大谁制倒对方

> **巳申合：此合效率最高，能量最大**，是巳火制了申金〔大任 · 03初级班 p30〕
>
> 巳申合，**巳中之火被申中之水克伤**〔大任 · 03初级班 p26〕
>
> 巳申合：巳火合申金，**火不生土**〔小任 · 15论合 p1〕

三句话看着打架，其实是三个侧面：

| 说法 | 在讲什么 |
| --- | --- |
| 「巳火制了申金」 | **常态**：火克金，巳主动 |
| 「巳中之火被申中之水克伤」 | **藏干层**：申中壬水反过来伤巳中丙火 |
| 「火不生土」 | **合而不生**（纯则不生）：一旦成合，原有的巳火生戊土被阻断 |

而定性一句话是：**「谁的力量大都可以制倒对方」**——所以巳申没有固定的主客，全看双方力量。

## 四、⭐ 巳申相刑，其意有三（直接回答问题②）

> **2、巳申相刑，其意有三：**
>
> **①.相生之意**
> **巳乃金之长生，申乃金之禄**，巳申相刑**土旺生金**，即巳与申相刑时若有一支天干透土（**戊申与巳** 或 **己巳与申**），即为土旺生金的意思，这时金旺可以刑去寅木。但巳申相刑为相生之意时，**必须天干有庚、辛金透出**才为金被刑旺。
>
> **②.相克之意**：一般是指在构成寅巳申相刑的基础上，巳再与申相刑即**火旺刑去申金**。
>
> **③.相合之意**：巳申相刑为**水旺**，乃六合之一，相刑（相合）两支必须有一支天干透水（**癸巳与申** 或 **壬申与巳**），即水旺生木。巳申相刑合化水，本为六合，但在构成寅巳申相刑的条件下，**巳申相合时寅不冲申，申也不冲寅**。
>
> 〔大任 · 17刑冲破害 p5〕

另一处复述得更直白：

> 寅巳申三刑看断原则：
> **1、巳刑申有相生之意**。庚金长生在巳、巳刑申，如果**巳火干透己土**生金论，故有相生之意。
> 2、巳刑申有相克之意。
> 3、巳刑申有相合之意。
> 如果**申金干透壬水，巳火干透癸水，则巳申合化水**论。如果柱中透甲乙木，则以水生木论，这时**申金就不冲寅木了，寅木也不刑巳了**。
> 〔大任 · 17刑冲破害 p10–11〕

### 三种意各自的触发条件

| 意 | 天干条件 | 结果 | 后续影响 |
| :-: | --- | --- | --- |
| **相生** | 透**土**（戊/己），且须**庚辛**透出 | **土旺生金**，金旺 | 金旺可**刑去寅木** |
| **相克** | 已构成寅巳申三刑、**火旺** | **火旺刑去申金** | — |
| **相合** | 透**水**（壬/癸） | **合化水**，水旺 | 水旺生木；且**寅不冲申、申不冲寅** |

**所以问题②的答案**：不是巳申有时候"变"成生，而是**天干透什么，决定了这组巳申走哪条路**——透土走生，透火走克，透水走合化。

> 要准确判断寅巳申相刑的吉凶，首先要搞清寅巳申相刑是**在什么情况下火旺，什么情况下水旺，什么情况下金旺**，并根据相刑后各个五行的旺衰对命局的影响，判断吉凶。
> 〔大任 · 17刑冲破害 p6〕

## 五、还有一层：申反克巳

小任在「地支六合逐组精析」表里，给巳申合专门列了常态之外的反转：

| 项 | 内容 |
| --- | --- |
| **专属含义** | ① 巳火克申金　② **金水成势时，申反克巳** |
| **实战断事** | ① 食伤合官 → **求贵/得权**　② 忌神被反制 → **大吉/求富** |
| **案例精析** | **乙木死木，巳为忌神，申子辰合水局**：巳本克申，但金水成势，**申反克巳**。忌神（巳）被制主大吉。断：食伤合官得贵，忌神受制得富，**富贵双全（正厅级）**。 |

> **反克条件**：巳申合的「申反克巳」**必须满足金水成势**（如三合水局、水旺透干），**否则仍按巳克申论**。
> 〔小任 · 课时笔记17 p4–5〕

> ⚠️ 原书此处是**条件式说明**（乙木日主＋巳＋申子辰水局），**没有给出完整八字**，故本节无四柱表。要看真盘请回查原书或另找命例。

**顺带一条**：同一张表里注明——**仅六合能闭库，且只有子丑、寅亥、辰酉、卯戌四组**。
**巳申不在闭库之列**，所以巳申合只论生克与合，不涉及闭库。

## 六、口径提醒：巳申破不在主口径里

传统／盲派六破含巳申：

> 子酉相破，丑辰相破，寅亥相破，卯午相破，**巳申相破**，未戌相破〔大任 · 17刑冲破害 p16〕
>
> **巳申相破是合中带破**，巳火中的丙火和戊土克申中的庚金和壬水，申中的壬水克巳中的丙火。这两种破是**很隐蔽的小矛盾**，一般不会轻易觉察，只有双方力量悬殊较大时才会显出来。〔大任 · 17刑冲破害 p20〕

⚠️⚠️ **这里要格外小心，本站曾把两套口径混过（2026-08-26 订正）**：

| | 组数 | 出处 |
|---|---|---|
| **传统／盲派六破** | 子酉·丑辰·寅亥·卯午·**巳申**·未戌 | 〔17刑冲破害 p16〕（上面刚引的） |
| ⭐ **本体系口径** | ⭐ **只有三组：子卯·卯午·午酉** | 〔**十八道法门 p41**〕明文「**子与酉之间没有相破的关系**」 |

⭐ **两处差别不止"含不含巳申"**：
**传统六破里的「子酉」，本体系明文否定；而本体系的「子卯」，传统六破里反而没有。**
⚠️ **本站一度写成"四正破（子卯／子酉／卯午／午酉）"——那是把传统的"子酉"混进了本体系口径**，已订正。
👉 权威表述见 [[07-作用方式总论#六、破]]。读到「巳申破」「子酉破」时，都要先问一句**出自哪套口径**。

## 七、实战决策顺序

1. **先看寅巳申是否三字全**
   - 不全 → 「巳申**以六合为主**」，按第三节论
   - 全 → 进入三刑，按第四节的三种意分流
2. **再看天干透什么**（这是分流的开关）
   - 透**土**戊己 ＋ 庚辛 → **土旺生金**，论生
   - 透**水**壬癸 → **合化水**，水旺生木，且寅申不冲、寅巳不刑
   - **火旺** → 巳制申
3. **看整体气势**：金水成势 → 申反克巳（小任）
4. 兜底一句：**「谁的力量大都可以制倒对方」**

## 八、命例

### 命例① 火旺，巳制申｜「制申金的主要是巳火」

〔大任 · 16实战技巧完整版 p1–2〕

|  | 年 | 月 | **日** | 时 |
| :-: | :-: | :-: | :-: | :-: |
| **天干** | 甲 | 壬 | **辛** | 甲 |
| **地支** | 寅 | 申 | 巳 | 午 |

大运：癸酉11 · 甲戌21 · 乙亥31

**原文分析**

> 辛日主生了壬水，而壬水生了年柱的甲寅财星为有作用，表示**命主想求财**之意，这是一个要点，日主想法有作用了。再看日支巳火杀星有作用否——首先**辛与巳是自合的关系**，表示日主要用这个巳火杀星。而原局是**木与火的气势**，表示日主要使用这个势去完成自己的使命，而仅有势还不行，要有制伏的对手……**此命巳申合寅申冲，午火也助克，表示要制这个申金劫财，此处制申金的主要是巳火**（寅和午可联想成巳的助手来理解）。

**这一例演示的是**：寅巳申三字全见，但**火旺**（木火成势 + 午助），所以走第四节的**②相克之意——火旺刑去申金**。同时可见「巳申合」与「寅申冲」并存时，**合是用来制的手段**。

**断解与反馈**

| # | 断语 | 依据 |
| :-: | --- | --- |
| ① | 聪明伶俐但不爱学习 | 透伤坐杀都有作用；伤生了财 |
| ② | 一生以求财为主，多方求财，可得小富 | 伤生财、伤制官；年财到时财都是财；时上官统财 |
| ③ | 工作多变，有个工作与执法或车辆有关 | 以日主看伤生财，以日支看官杀制劫财＝执法；**申与巳都有车辆的象** |
| ④ | 家庭富裕，可得祖力 | 年柱财在势中共同制申金，有作用 |
| ⑤ | 妻为远方之人，得妻力，妻贤慧能干 | 财也看妻；年时为远方，妻宫有大作用 |
| ⑥ | 社交广泛，为人热情大方 | 年时都在势中；木火主热情 |
| ⑦ | 在社会中有影响力和号召力 | 原局有气势，日主**辛巳自合**主导这个势去做事 |
| ⑧ | 生意上是老板，工作中小有职权 | 日主辛巳合，表小职权 |
| ⑨ | 口才特好使 | 时上财虚，表口才好 |

> **反馈**：父曾为包工头，当地属有钱之人；自己原接父的工程干，挣钱后通过关系干上**交警**，有点职务；同时开有一家酒店由妻子管理，生意不错；自己另从事中介行业。

> 💡 注意③——「**申与巳都有车辆的象**」，最后应在**交警**上，正是巳申这组的取象落点。

> 🔍 **此盘的入手四步完整拆解**（日干生壬→壬生甲财＝求财；日支辛巳自合＋巳申合制劫＝执法；两条线并行故断"警察＋开酒店"）见 [[八字08-这套民间八字的特点与断命总纲#二、拿到一个八字，从哪里入手|08篇入手命例]]。

### 命例② 巳申合，得官｜厅级干部

〔大任 · 六爻 p7〕

|  | 年 | 月 | **日** | 时 |
| :-: | :-: | :-: | :-: | :-: |
| **天干** | 壬 | 戊 | **乙** | 丙 |
| **地支** | 辰 | 申 | 巳 | 子 |

**原文分析**

> 断：是个**贵命，当官的，可达厅级以上**，主搞行政方面的工作。
> 反馈：是个厅级干部。
> 命中**月令为官带财帽，巳申合自己得到了官**，故命贵。搞行政而不主财有关，是看**戊通巳**（干支通用）。

**这一例演示的是**：巳申合的**「得到」**义——月令申是官，与日支巳一合，官就归了自己。合在这里不是制，是**取得**。

**拆解**

1. 乙木日主 → 金为官杀。月支**申**＝官，其上透**戊**＝财 → 「官带财帽」
2. 日支**巳**与月支**申**相合 → 官被合到日支（自己的位置）→ **得官**
3. 为什么是行政不是财口？—— **戊通巳**（巳藏戊土），财气归到巳里，不单独作财论

### 命例③ 木火成势，巳申合制申｜财源在时柱

〔大任 · 六爻 p9〕

|  | 年 | 月 | **日** | 时 |
| :-: | :-: | :-: | :-: | :-: |
| **天干** | 乙 | 辛 | **己** | 壬 |
| **地支** | 卯 | 巳 | 巳 | 申 |

**原文分析**

> 此命月柱**辛巳自合**，辛金当母看，早克母的象，丙戌年丙辛一合，辛则去（合去的用法），此年**丧母**。
> 再看命中**木火成势，巳申合制申金**，申为财源头又在时柱，**命可小富**，实际在外发展财运不错。

**这一例演示的是**：同样木火成势 → 仍走**相克之意**，双巳制时支申。与命例①对照，**两例都是火旺制申**，但一个应在执法、一个应在求财，差别在十神与宫位。

**🔍 拆解：同样"火旺制申"，凭什么一个断执法、一个断求财**（我补的推理，非原文，可推翻）

己土日主（乙辛**己**壬／卯巳**巳**申）。**申＝伤官**（己生金）｜壬＝正财｜乙、卯＝官杀｜**辛＝食神**。

**第1步·先看申在这个盘里是什么身份**

| | 命例①（甲壬**辛**甲／寅申**巳**午） | 本例（乙辛**己**壬／卯巳**巳**申） |
|---|---|---|
| 日主 | **辛金** | **己土** |
| **申是什么** | **劫财**（同类，分我财的人） | ⭐ **伤官**（我生的，是财的源头） |
| 制申＝制什么 | 制**竞争者** | 制**财源** |
| 断出来 | 执法（管人） | **求财** |

⭐ **同一个申、同样被火制，因为日主不同，十神身份就不同，结论自然不同。**
这正是第5章那句"**先定角色再谈吉凶**"的实证。

**第2步·为什么"财源在时柱"就能小富**
```
申（伤官）＝ 财的源头（土生金、金生水，壬水才是己的财）
   而申在【时支】，壬在【时干】—— 财与财源同在时柱
        ↓
第13章：「八字有财星，伤食是其原神」「财星落于时上做功」
        ↓
   ⭐ 双巳合制申 = 制住了财源 → 制什么得什么
        ↓
      可小富
```

**第3步·顺带看"早克母"那条**
```
月柱【辛巳】自合（第7章：自合能做功）
   辛＝食神，此命取【辛当母看】
        ↓
自合＝合而制之 → 母星本就处在被制状态
        ↓
丙戌年：丙辛合 → 辛被合去（合去的用法）
        ↓
   此年丧母
```
> 💡 **注意月柱同时干两件事**：辛巳这一柱，**自合制辛（应母）**，而**巳又去制申（应财）**。一柱两用，各表各的（对照 [[八字09-应期怎么定（中级班专讲）]] 命例H 的"各表各的"）。

### 命例④ 巳申合动，定应期｜合动巳火去刑寅

〔大任 · 03初级班 p40–41、16实战技巧完整版 p17〕

|  | 年 | 月 | **日** | 时 |
| :-: | :-: | :-: | :-: | :-: |
| **天干** | 壬 | 壬 | **庚** | 辛 |
| **地支** | 子 | 寅 | 辰 | 巳 |

大运：甲辰 · 乙巳

**原文分析**

> 此造**巳火七杀为儿，被寅木财星穿倒**，生女孩，而且父母不喜欢孩子（父母宫穿儿女宫），因为**月令寅木穿巳**，月为父母宫。**甲辰运戊寅年，寅巳刑为动**，到公检法部门工作。**乙巳运甲申年，巳申合，合动巳火刑寅木，主破财**——因为老婆破财（因为乙为妻，巳火头上坐了乙木），**辰中乙木为老婆在夫妻宫**，辰土又为偏印、印又为母，是因为**丈母娘**破财。

**这一例演示的是**：巳申合的**应期**用法——原局只有巳、没有申，靠**流年甲申**把申送来，巳申一合，**合动巳火**再去刑寅，连锁反应落到具体人事上。

**拆解**

1. 庚金日主 → 火为官杀，**时支巳＝七杀＝儿子**；寅为财
2. 原局**寅巳相穿**（月支穿时支＝父母宫穿儿女宫）→ 生女孩、父母不喜孩子
3. **甲辰运 戊寅年**：寅到，**寅巳刑为动** → 进公检法
4. **乙巳运 甲申年**：申到 → **巳申合** → 把巳**合动**了
5. 巳一动就去**刑寅木**（财）→ 破财
6. 落到谁身上？乙为妻、**巳火头上正坐着乙木**（乙巳运）；辰中乙木是老婆又在夫妻宫；辰土为偏印、印又为母 → **丈母娘**

> 💡 关键在「**合动**」二字：合不只是把两个字绑住，还能**把其中一个字激活**去作用第三个字。本例链条是 **申来 → 合巳 → 巳动 → 刑寅 → 破财**。
