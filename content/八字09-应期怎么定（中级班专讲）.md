## 二、流年应期的三类（中级班 p36-38，原文照录）

### ① 字到即应——最常用的一条

> 「八字中某字在流年（大运）中出现**或见其禄神与原身**，则此年（运）要发生与该字有关的事情。流年（大运）中该字产生什么样的作用，**就如同原局中该字发生的作用一样**，这叫此字在流年（大运）的应期。」

这条有两个关键：
- **认字要认三层**：字本身 ／ 它的禄神 ／ 它的原身（癸见丑为禄→丑到即癸到）
- **作用照搬**：这个字在原局是被制的，到了运年出现就是"被制的时间到了"；原局是做功的，到了就是"功成的时间到了"

**命例A**（中级班 p36）

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 坤 | 戊 | 壬 | 甲 | 甲 |
|  | 申 | 戌 | 子 | 寅 |

> 以子为夫宫、申为夫星，**申子三合＝夫到夫宫之意** → 结婚应在**壬申年**（夫星出现、拱入夫宫的应期）。
> 大运到**己未运的未运**，未穿了子（夫宫）→ 婚姻当出问题，应期在**丙子年**（夫宫子水在流年出现见穿）。

**🔍 拆解**（我补的推理，非原文，可推翻）

**为什么"申是夫星"？** 甲木日主（坤造），**女命看官杀为夫**。申的本气是庚金，庚克甲 → **七杀**。所以申＝夫星。
**为什么"子是夫宫"？** 子是**日支**，日支即正宫（第4章）。

**结婚那一年的机关：**

```
原局：申（夫星）……子（夫宫）    ← 申子之间隔着戌，未成局
              ↓
壬申年：申到位
              ↓
申 + 子 + （辰在哪？无辰）→ 申子半合水局
              ↓
"夫到夫宫" = 丈夫进了家门 → 结婚
```

⚠️ 原文说"申子三合"，严格讲**申子辰缺辰，是半合**（第7章④：半合必须有中神，申子有中神子，成立）。**中神在夫宫，所以是"往夫宫合"**。

**婚变那一年的机关：**

```
己未运：未穿子（夫宫）           ← 大运把"宫会被穿"这件事摆上台面
              ↓
丙子年：子到位                    ← 被穿的那个字自己出现了
              ↓
第12章：受伤状态的字，出现之时就是应期
              ↓
婚姻出问题
```

⭐ **两个应期，用的是同一条规则的两面**：
- 结婚：**好事的字（夫星申）到位** → 事成
- 婚变：**已受伤的字（夫宫子）到位** → 灾应

**判断"到位是吉是凶"，看它在原局是什么状态**——这与题库【题32】那条完全一致。

**命例B**（中级班 p36）

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 坤 | 庚 | 辛 | 辛 | 癸 |
|  | 寅 | 巳 | 酉 | 巳 |

> 日主之禄（酉）被两巳火克坏，食神癸水在局中很重要。行**丙子大运**，相当于**癸落入地支**——原来癸受天干庚辛之生，到地支就没法受生了（酉金自身受克，无法生子水），反被巳绝寅泄。到**壬午年**，午一冲子水，食神被坏 → 命主被歹徒杀害。

> ⚠️ 这例演示的是**大运让一个字"换了位置"就换了状态**：癸在天干有生，落到地支反被绝泄。虚实的思路一直贯穿到应期。

**🔍 拆解：这题最难的是"癸落入地支"五个字**（我补的推理，非原文，可推翻）

辛金日主。先定角色：**癸＝食神**（辛生癸，阴生阴）；**酉＝日主之禄**（辛禄在酉）。

**第1步·原局的癸，日子过得不错**

```
天干： 庚  辛  辛  癸
        ↘  ↘  ↘  ↗
      庚辛金 都能生癸水       ← 癸在天干，上有三个金源
```

**第2步·丙子运，"癸落入地支"是什么意思**

**子是癸的禄**（第6章禄表：癸禄在子）。所以**大运走子＝癸这个字换到地支去了**——就像一个人从楼上搬到楼下。

**换了位置，处境全变：**

| | 癸在天干时 | 癸（＝子）在地支时 |
|---|---|---|
| **谁来生它** | 庚、辛三个金**都能生** | 只能靠**酉**生——但酉自己被两巳克坏了，**自身难保，生不动** |
| **谁来伤它** | 天干无人克 | **巳绝子**（第7章四绝：子巳）、**寅泄子**（水生木） |

⭐ **同一个癸，在天干是"有源之水"，落到地支变成"无源又被绝泄"。**

**第3步·壬午年补最后一刀**

**午冲子** → 食神被彻底冲坏 → 命主被歹徒杀害。

> 💡 **为什么食神坏了会致命？** 辛金日主，**禄（酉）已被两巳克坏**——身体那一头本来就危；食神癸是"泄秀、护身"的出口，也是原文说的"局中很重要"的字。**两处支撑同时崩塌**。

⭐ **本例真正的教学点**：第3章的虚实不只用在原局——**大运会让一个字改变所在的层（天干↔地支），层一变，它的处境（谁生它、谁克它）整个换一套**。
这与第3章的「**反常律**」（喜虚者见实、喜实者变虚，皆为反常）是同一件事的两种说法。

### ② 藏干透出即应

> 「八字**地支中某字遁藏，在大运或流年的天干出现**，也是地支此字的应期，表明这个字所代表的信息要发生变化。如原局有戌，流年或大运出现丁，**此丁就可以代表戌的信息，其丁的作用就相当于戌的作用**。」

这就是初级班反复用的「丁即未」「癸即丑」「丙即戊」——**天干是地支的替身**。

**命例C · 蒋介石**（中级班 p37，与初级班 p8、p20 同例互见）

> 🔍 **此盘的完整拆解见 [[八字10-做功到底是什么#五、做功会被大运逆转|10篇]]**：为什么"制官与官的原神"是顶级；甲辰运三个动作（甲透干／甲得辰为根／甲合日主）如何攻守易位；以及中级班p30那句"亥入辰墓被保护"与p37的解法如何互补。

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 乾 | 丁 | 庚 | 己 | 庚 |
|  | 亥 | 戌 | 未 | 午 |

> 原局火与燥土成势制亥水，亥中含甲木官星，**制官与官的原神** → 大贵命。
> 行**甲辰运**：亥中甲旺透，**无法得制**，又合到日主 →「表示**不仅制不住对手，反被对手制了**」，故兵败台湾。

> ⭐ 这是**做功被逆转**的标准案例：原局功成＝大贵，运里功破＝败。参见 [[八字10-做功到底是什么#五、做功会被大运逆转]]

### ③ 运年与原局产生作用即应——四字诀

> 「流年或大运与八字产生**冲、合、刑、穿、墓**，都是一种应期，**流年与大运产生的这些作用也是应期**。作用到哪个字，哪个字在此运此年就会发生应事。」

**四字诀**（中级班 p37，⭐ 背下来）：

| 作用 | 主什么 |
|---|---|
| **合** | 主**到** |
| **冲** | 主**动** |
| **墓** | 主**收** |
| **穿** | 主**伤** |

**配套的反向规则**（p37-38）：

- 原局**有合** → 以**冲**为应
- 原局**有冲** → 以**合**为应
- 流年**合大运** → 为**合动**
- 流年**冲大运** → 看**当运不当运**：**当运为冲去，不当运为冲起**

> 💡 最后这条「当运/不当运」是中级班独有的，初级班没有。**当运＝正走这步运的本气**。

**命例D**（中级班 p38）

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 乾 | 乙 | 庚 | 辛 | 壬 |
|  | 巳 | 辰 | 卯 | 辰 |

> 年上乙木为父，有气而弱，乙庚合 → **原局合伤父星**，得时而应父灾。
> **丁丑运**：劫财庚临旺地 → 当在此运丧父。
> **甲戌年**父逝。为何应甲戌？「原局合，**甲庚冲之应**」——甲庚冲，弱神冲旺神，**非冲而不合，而是冲而应合之应**。因**冲能动庚**，庚一动，则克伤乙木。

> ⭐ 这例把「原局有合 → 逢冲为应」讲透了：冲不是来破坏的，冲是来**把那个合激活**的。

**🔍 拆解：「冲而应合之应」这句话怎么读**（我补的推理，非原文，可推翻）

辛金日主。**乙＝偏财**（辛克乙，阴克阴）→ **财看父**，所以年上乙木是父星。

**第1步·原局已经埋好了"克父"**

```
乙（父星，年干）—— 庚（劫财，月干）
      ↑ 乙庚合，而合中看克 → 庚金克乙木
      ↑ 乙坐巳（虚地，第3章：乙巳为虚透）
      ↓
原文：「有气而弱」「原局合伤父星」——父星已经处在被伤的状态，只等应期
```

**第2步·丁丑运为什么定在这一步**

「**劫财庚临旺地**」——丑是金库／湿土能生金（第2章：辰丑土能生金），**庚在丑运得力**。
→ 那个"合伤乙"的手，**在这一步运里变强了** → 克父的事定在此运。

**第3步·甲戌年那句绕口的话，拆开是这样**

原文：「甲庚冲，弱神冲旺神，**非冲而不合，而是冲而应合之应**。」

一般人的直觉是：**甲来冲庚，把庚冲开了，那乙庚合不就解了、父不就没事了吗？**

**恰恰相反。** 原文说的是：

```
甲（弱）冲 庚（旺）
   ↓
弱冲旺，冲不倒它 —— 所以不是"把合冲散"
   ↓
但冲能【动】它 —— 「冲能动庚」
   ↓
庚一动，它手上那个"合克乙"的动作就【执行】了
   ↓
乙木被克伤 → 父逝
```

⭐ **「冲而应合之应」＝ 冲不是来拆合的，是来给这个合按下启动键的。**

**第4步·什么时候冲是"拆"、什么时候是"启动"？**

这是本例最该带走的判断：

| 力量对比 | 冲的效果 |
|---|---|
| **冲方强**（旺冲弱） | **冲开、冲坏** → 合被拆散，被合的字解放 |
| **冲方弱**（弱冲旺） | **冲不倒，只能冲动** → 合中的动作被激活、执行 |

本例是**甲弱冲庚旺** → 属第二种。

> 💡 这条与第7章「合绊逢冲则解」不矛盾——**那条说的是力量相当或冲方够强的情形**。**力量对比才是分水岭。**（第8章效率表也反复强调：「一方之势一定要大于另一方之势，否则这些冲都不能作用」）

## 三、初级班给的补充规则（p52，与中级班配套用）

> 「**原局有什么字，就应什么事**——只是原则上讲的，但实际使用时还要注意到**藏干**以及**禄与原身**的关系。」

再加一条最实用的：

> 「因辰土在原局是**受伤的状态**，**出现之时就是受伤的应期**。」（初级班 p20）

**命例E**（初级班 p52）

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 乾 | 庚 | 己 | 庚 | 丁 |
|  | 午 | 卯 | 午 | 亥 |

> 原局卯木看父，**卯午双破** → 父伤之意（原局信息）。
> 行**庚辰运**：庚表日主到，原局之亥入大运之辰墓（亥不生卯了），辰又穿原局之卯 → 父要有伤在此运。
> **戊子年**：子辰拱局（辰加力又表辰动），子冲原局之午 → 午动去破卯；子又直接破卯木。
> 结果：此年父亲盖房从高处摔下，死里逃生。

> 三层结构一目了然：**原局有不利父的信息 → 大运表父受伤的时间 → 流年到位了。**

**🔍 拆解：三层是怎么各司其职的**（我补的推理，非原文，可推翻）

庚金日主。**卯＝正财**（庚克木，阳克阴）→ **财看父**，卯是父星。

**原局层·父星本来就伤着**

```
卯 被 午 破（第7章：卯午破）—— 而且是【双破】：年支午、日支午，两个午都在破卯
        ↓
父星长期处于受损状态 → "父伤之意"
```
⚠️ 但**破不表制**（第7章⑩），只表"破坏、无情、不通"——所以**原局只是"有此象"，不到出事的程度**。

**大运层·庚辰运把伤口撑开**

三件事同时发生：

| 大运动作 | 效果 |
|---|---|
| **庚到** | 庚＝日主到位（日主亲自入局） |
| **原局的亥 → 入大运的辰墓** | ⭐ **亥本来是生卯的**（亥藏壬甲，水生木）；亥一入墓，**卯的水源断了** |
| **辰穿原局的卯** | 直接打父星 |

⭐ **中间那条最关键**：不是直接打父星，是**先断掉父星的补给**。原文「**亥不生卯了**」五个字，说的就是这个。

**流年层·戊子年三管齐下**

```
① 子辰拱局 → 辰得力、且"辰动了"（大运那个辰被激活）
② 子冲原局的午 → 午动 → 动起来的午去破卯
③ 子直接破卯（第7章：子卯破）
        ↓
   三条同时打在卯上 → 父从高处摔下，死里逃生
```

**为什么是"死里逃生"而不是"父亡"？**
我的理解（非原文）：**打卯的全是"破"**（子卯破、卯午破），而**破不表制、不主生死**，只主"破坏、不通"。若换成冲、穿、入墓，性质就重了。
> 💡 对照本篇命例D：那例是**合＋冲激活克**（庚克乙），才应了"父逝"。**作用方式的性质，决定灾的轻重。**

⭐ **本例最该带走的**：三层各干各的活——
| 层 | 职能 |
|---|---|
| **原局** | 说明"这事会有" |
| **大运** | **创造条件**（断补给、加力量），说明"哪十年" |
| **流年** | **临门一脚**，说明"哪一年" |

## 四、大运的三种情形（`十八道法门.pdf` p55 第十八道法门）

> 「大运是命局的延伸，也可称之为**命局的第五柱**……大运还可以改变原命局的吉凶状况。」

| # | 情形 | 断法 |
|---|---|---|
| ① | 原命局中的**事**到大运时体现出来了 | 此大运要**应这件事** |
| ② | 原命局中的**字**到大运出现了 | 要应**与这个字有关的事**（称「命中干支到大运」） |
| ③ | 原命局中**没有的字**在大运出现了 | 看此字对原局组合**产生了什么变化**，吉凶针对具体命定 |

> 还有一种：「**流年可不通过大运而直接对原命局发生关系**而产生吉凶……但这种情况都有特殊规定和使用条件，**具有一定功底者可使用**。」

## 六、中级班另外三节，都直接服务于"怎么找应期"

### 6.1 十三、具体分析单项事情（p35）—— 先锁字，再断事

> 「分析单项事情是在分析原命局的基础上针对**一件事**的吉凶进行分析。**首先要找准那一个字代表所关心的事**，然后用这个象结合作用方式及本身的象来综合分析。」

**命例F · 一个八字六问六答**（中级班 p35）

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 乾 | 丙 | 癸 | 乙 | 丙 |
|  | 辰 | 巳 | 酉 | 戌 |

| 问什么 | 锁哪个字 | 断解 |
|---|---|---|
| **工作** | 杀印 | 癸虚透→无文化；酉杀在主位喜制伏，但**辰酉一合反而制不住酉杀** → 杀表辛苦：既无文化又无工作，**体力劳动者** |
| **婚姻** | 酉为宫，辰戌都为星 | 辰来合酉使酉不被制，辰看妻 → **此妻难留**（实际离异一次）；戌看二妻，长与宫穿但制酉 → 感情不好但可助自己 |
| **财运** | 酉 | 原局若制了酉则有工作又有财，但没制伏；辰看财坏局 → **财运不好，普通人** |
| **能力** | 乙、丙、癸 | 乙坐酉杀虚，透丙火泄但丙无作为，癸印虚 → **不爱学习、想法多、爱好广泛不实际** |
| **身体** | 酉 | 乙坐酉杀，**制不住杀就是病**；酉为金表筋骨，坐支为腰位 → **腰疼**（实际有） |
| **子女** | 杀 | 杀看儿，制不住坏了；时上戌穿也表坏；酉为妻宫、时为生殖，**宫都坏** → **不生育** |

> 「针对不同的事情，**首先要找出代表此事物的某一字**，然后当作分析，吉凶自然就看明白了。」

**🔍 拆解：六个答案其实是同一个答案**（我补的推理，非原文，可推翻）

乙木日主。先把角色定齐：

| 字 | 对乙木是 | 备注 |
|---|---|---|
| **酉** | **七杀** | ⭐ **同时还是日支＝婚姻宫** |
| 辰、戌 | 正财／正财 | 男命**财看妻** |
| 丙（年、时） | 伤官 | |
| 癸 | 偏印 | 坐巳，**虚透**（第3章：癸巳虚） |
| 巳 | 伤官 | |

**⭐ 六问六答，全都绕着一件事：酉杀制没制住**

原文六条断解，看着各说各的，其实**五条都回到同一个判断**——

```
        酉（七杀）在日支主位
                ↓
        七杀本该被制伏才好（第7章⑮：杀喜制）
                ↓
        但【辰酉一合】把酉护住了 → 制不住
                ↓
   ┌────────┬────────┬────────┬────────┐
 工作      财运      身体      子女      婚姻
制不住杀   没制住酉   制不住杀   杀制不住   辰来合酉
＝辛苦     ＝没财     ＝病       ＝伤子     ＝妻难留
体力劳动   普通人     腰疼       不生育     离异一次
```

⭐ **这就是"抓重心"的实际样子**（下一节 6.2 讲的正是这个）：**一个盘的核心矛盾往往只有一个，六个问题是它的六个侧面。**

**几处具体的跳步补一下：**

**① 为什么"辰酉合"反而是坏事？**
合在这里起的是**保护**作用——第8章讲过「**合可以保护被制的字**」。杀本该被制，**一被合住就制不动了**。
> 同一条规则的两面：想制它 → 合是坏事；想保它 → 合是好事（对照本篇命例A"申子合＝夫到夫宫"就是好事）。

**② 为什么"腰疼"能断得这么准？**
两层叠：**酉为金 → 主筋骨**（第2章十干类象：辛＝筋骨、小骨骼）＋ **酉在日支 → 日支对应腰腹**（第4章身体层）。
**部位＝宫位定，病性＝五行定。** 这是第15章断病三步的标准用法。

**③ 为什么"不生育"要拉上两个字？**
「**酉为妻宫、时为生殖，宫都坏**」——
- 酉（妻宫）被辰合、制不住
- 时柱戌（主生殖、门户，第4章）与酉相穿
**两个相关的宫都坏了**，才敢下"不生育"这种重断（第14章：单一作用不断重事）。

**④ "癸虚透→无文化"**
癸是**印**，印主学历文凭（第5章）。**癸巳是虚透**（第3章虚实表）→ 印虚 → 文凭不高。
> 对照第15章：「印虚透 → 文凭不高」是标准判据。

### 6.2 十五、实践运用，抓其重心（p38）

> 「当一个八字到手，通过仔细分析评判，**先找到八字的敏感点**，由此重心逐渐引伸出别的事物。」

**命例G**（中级班 p38）

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 乾 | 癸 | 辛 | 壬 | 戊 |
|  | 丑 | 酉 | 子 | 申 |

> 一片金水之势，**原局有几个重点**：金多入丑墓／年干透刃被戊杀合／时上印带官帽／日支合丑。
> 断：1宜当兵回来有工作（癸戊为配杀表当兵）2有个小职务权不大（时上印带官帽表职务）3文化不高不爱学习（**印入墓不开**）4工作在企业不会到政府、大型企业（丑看工作在年）……

**🔍 拆解：什么叫"先找敏感点"**（我补的推理，非原文，可推翻）

壬水日主（癸辛**壬**戊／丑酉**子**申）。**戊＝七杀**｜**辛、酉、申＝印**｜**丑＝正官，且是金库**｜癸、子＝比劫（⚠️ **2026-08-26 订正**：**壬的禄是【亥】不是子**；**子是壬的羊刃**——同时是**年干癸的禄**）。

**第1步·原文列的"几个重点"，就是敏感点**

```
① 金多入丑墓        ← 一大堆印，全被丑收着
② 年干透刃被戊杀合   ← 癸（刃）被戊（杀）合住
③ 时上印带官帽      ← 戊坐申，戊是杀、申是印 → 印带官帽（第6章带象）
④ 日支合丑          ← 子丑合
```

⭐ **"敏感点"＝盘上少数几个"有动作"的地方**。这个盘一片金水，看着均匀，但真正在发生事情的只有这四处。**抓住它们，别的都是背景。**

**第2步·四条断语，各出自哪个敏感点**

| 断语 | 出自 | 怎么推 |
|---|---|---|
| **宜当兵** | ② | **癸戊合**——刃（凶悍、武）被杀（纪律）合住 → **羊刃配杀＝军人象**（第13章官运原则4） |
| **有小职务但权不大** | ③ | **印带官帽**＝有官身（第6章带象三型之一）；但只在**时柱**、且印被丑收着 → 权不大 |
| **文化不高不爱学习** | ① | **印＝文凭**（第5章），而**印入墓不开** → 文凭拿不出来 |
| **工作在企业非政府** | ④ | **丑＝官＝工作**，而丑在**年**（宾位、且是库）→ 不是自己主位上的正经官职 |

**第3步·这个盘教的方法**

```
不要试图"综合出一个总结论"
        ↓
① 先扫一遍：哪几个字有明确动作？（合、冲、穿、入墓）
② 每个动作单独问：它连着哪个十神？在哪个宫位？
③ 一个动作出一条断语
```

> ⭐ **与命例H（各表各的）的区别**：
> - **命例H**：作用极多（九种），方法是"**一项一项拆**"
> - **本例**：作用不多，但**藏得深**（入墓、带象、合），方法是"**先找到它们**"
>
> **一个是"太多要分开"，一个是"太少要找出来"。** 两例正好覆盖两种盘。

### 6.3 十一、同时出现几种作用方式时如何分析（p32-33）

> 「如果原局中形成了**一方的势**，就要看**有没有制伏的对手**。如果没有制伏对方存在，**就要通过象来解读**（当然象与作用方式是并存的）。」
> 「**大多八字都没有势**，而是以各种形式的作用方式体现出来，这时就要整体分析，**找各自作用路线**，只要有作用路线存在，就一定有表现的事物出现，然后把各自代表的意义提取出来。」

**这段极重要**——它回答了 [[八字10-做功到底是什么]] 里那个悬案：**有势却找不到对手时怎么办？答案是转用象法，不是直接断"差命"。**

**命例H · 多种作用方式并存怎么拆**（中级班 p33）

|  | 年 | 月 | 日 | 时 |
|---|---|---|---|---|
| 乾 | 癸 | 乙 | 辛 | 戊 |
|  | 丑 | 卯 | 酉 | 戌 |

> 地支有卯酉冲、卯戌合、酉戌穿、丑酉合、丑戌刑；天干有乙辛冲、戊癸合、乙克戊、癸生乙。这么多作用方式怎么看？
> 「当出现这种情况时，我们是**各表各的作用，各表各的意思，一项一项来分析**。」
> - 日主辛金生癸水食神（癸有聪明之意），癸又生乙财 → **日主的想法有用**
> - 日支坐酉禄冲卯木财，**禄冲财表示得财** → 通过思维挣钱（食表思维）
> - 卯酉冲对取财是得财，但财在月令也看父 → **与父相克**；月令也看兄弟，因冲不在一起
> - 时上戌穿酉，日主通禄不喜制（对身体不好），这时**丑酉拱合有保护的意思** → 身体无大碍
> - 卯木财在月令表别人的位置，**戌合卯把财拉回来归了自己**（年月表别人，日时表自己）
> - 天干癸戊合、地支戌丑刑，年月表祖 → 把祖业拉到了时；戌刑丑 → **离祖**

**🔍 拆解：没有势的盘，怎么做到"各表各的"而不乱**（我补的推理，非原文，可推翻）

辛金日主。这个盘**九种作用挤在一起**，之所以不乱，是因为**每条断语只调用其中一两个作用，各走各的路线**。

**先定角色**：癸＝食神｜乙＝偏财｜戊＝正印｜**酉＝日主之禄**（辛禄在酉，且是日支）｜卯＝偏财｜丑＝偏印｜戌＝正印

**六条断语，六条独立路线：**

| # | 走哪条线 | 逻辑 |
|---|---|---|
| 1 | **辛 → 癸 → 乙** | 日主生食神、食神生财 → **想法能变现**（第9章入手第①步：日干有生，看它生去干什么） |
| 2 | **酉 冲 卯** | **禄冲财＝拿自己的力量去够财**；食（癸）表思维 → **靠脑子挣钱** |
| 3 | 同一个卯酉冲，**换个身份读** | 卯**在月令也看父**（财看父）→ 冲父星 → **与父相克**；月令也看兄弟，**冲＝不在一起** |
| 4 | **戌 穿 酉** vs **丑 合 酉** | 戌穿酉（禄＝身体）本该伤身，**但丑酉合护着酉**（合＝保护）→ **身体无大碍** |
| 5 | **戌 合 卯** | 卯（财）在月令＝别人的位置；**戌在时柱＝自己的位置**；戌把卯合过来 → **财归自己**（第9章主宾） |
| 6 | **癸戊合 ＋ 戌刑丑** | 年月表祖，时表自己；合与刑把年月的东西**拉到时柱** → **离祖** |

⭐ **看出门道了吗**：

- **同一个"卯酉冲"，第2条读成"得财"、第3条读成"克父"** —— 因为**卯有两个身份**（财、父）
- **同一个"酉"，第4条既是被穿的对象、又被丑合保护** —— **一伤一护，最后结论是"无大碍"**
- 第5条和第6条都是"**把东西从别处拉到自己这边**"，只是拉的东西不同（一个是财、一个是祖业）

**方法总结（这才是本例的价值）：**

```
盘上作用很多时，不要试图"综合成一个结论"
        ↓
① 先把每个字的【全部身份】列出来（一个卯 = 财 = 父 = 兄弟）
② 一次只问一件事，只调用与它相关的那一两个作用
③ 同一个作用，问不同的事时可以读出不同的意思
④ 一伤一护同时存在时，看谁力量大 → 定最终结论
```

> 💡 这正是第11章那句「**大多八字都没有势……要找各自作用路线，只要有作用路线存在，就一定有表现的事物出现**」的操作版。
> **有势的盘（如国务院总理那个）是"一条主线贯穿"；没势的盘是"多条支线并行"。** 两种盘的读法根本不同。

## 七、应期速查卡

```
【定应期五步】

第1步 先从原局确认：这件事是不是必然要发生的？
      （不必然 → 别往下找，运年变不出来）
              ↓
第2步 锁定代表这件事的那一个字
      （十三章：找准那一个字，再结合象与作用方式）
              ↓
第3步 看这个字在原局是什么状态
      被制？做功？入墓？受伤？—— 状态决定应吉还是应凶
              ↓
第4步 找大运：三种情形
      ①原局的事到运了 ②原局的字到运了 ③运带来新字改变组合
              ↓
第5步 找流年：三类应期 + 四字诀
      ①字到（含禄神、原身）②藏干透干 ③冲合刑穿墓
      合者主到 · 冲者主动 · 墓者主收 · 穿者主伤
      原局有合→逢冲应 · 原局有冲→逢合应
      流年合大运＝合动 · 流年冲大运＝当运冲去/不当运冲起
```
