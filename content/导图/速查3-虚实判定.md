# 速查表 · 虚实判定
> 只看本柱：坐下与天干**同五行、生天干、或是天干（及生它之五行）的墓库**为实，其余为虚。细节回第3章。

| 干 | 实（有根或有生） | 虚（无根无生） | 留意 |
|---|---|---|---|
| **甲** | 甲寅、甲辰、甲子 | 甲戌、甲午、甲申 | ? 甲辰、甲子另一表判虚 |
| **乙** | 乙亥、乙卯、乙未 | 乙巳、乙酉、乙丑 | |
| **丙** | 丙寅、丙午、丙戌 | 丙子、丙申、丙辰 | |
| **丁** | 丁巳、丁卯、丁未 | 丁亥、丁丑、丁酉 | 丁亥论虚（坐绝地） |
| **戊** | 戊戌、戊午、戊辰 | 戊子、戊申、戊寅 | ? 戊辰实战按虚读；戊寅本气克干论虚 |
| **己** | 己巳、己未、己丑 | 己亥、己酉、己卯 | ? 己丑实战按虚读 |
| **庚** | 庚申、庚辰 | 庚子、庚午、庚寅、庚戌 | 庚戌燥土脆金论虚 |
| **辛** | 辛丑、辛酉 | 辛巳、辛亥、辛未、辛卯 | 辛未论虚 |
| **壬** | 壬申、壬子、壬辰 | 壬戌、壬午、壬寅 | ? 壬辰另一表判虚 |
| **癸** | 癸亥、癸酉、癸丑 | 癸巳、癸未、癸卯 | **癸卯是虚**（易错） |

| 实了怕什么 | 柱 | 怕 |
|---|---|---|
| 木根 | 丙寅、丁卯 | 申酉金冲克 |
| 火根 | 丙午、丁巳、戊午、己巳 | 亥子水冲绝 |
| 库根 | 丙戌、丁未 | 辰冲、丑冲 |
| 金根 | 壬申、癸酉、庚申、辛酉 | 巳午火克；癸酉辛酉尤怕**戌穿** |
| 水根 | 壬子、癸亥 | **戌未燥土**最烈 |

| 虚透之十神 | 读成 | 通根读成 |
|---|---|---|
| 财 | 才华、口才、会来事 | 钱财资产 |
| 官 | 名气、虚职 | 实权实职 |
| 印 | 名气、文凭头衔 | 靠山、实权、根基 |
| 食伤 | 口才、爱自由 | 专业技能、作品 |

**两句总纲**：「**虚干不生，虚干怕合**」｜「**实干怕坏根**，刑穿破怕支神升天」。**反常律**：喜虚者见实、喜实者变虚，大凶。
