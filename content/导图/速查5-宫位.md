# 速查表 · 宫位
> 一柱读六遍：**看什么事，就切到哪一层**。「宫不变，任何东西都是从宫变化出来的」。细节回第4章。

| 层 | 年柱 | 月柱 | 日柱（日支） | 时柱 |
|---|---|---|---|---|
| **六亲** | 祖上、父母、外戚长辈 | 父母、兄弟 | **配偶**（日支） | 子女后代 |
| **年龄（一柱）** | 0–18 | 19–36 | 37–54 | 54 以后 |
| **年龄（一字）** | 干 1–9／支 9–18 | 干 18–27／支 27–36 | 干 36–45／支 45–54 | 干 54–63／支 63–72 |
| **空间** | **远方** | 祖籍 | 现居 | **门户**、外地 |
| **人际** | 外人、长辈 | 同学、同事、领导 | 至亲 | 晚辈、学生、下属 |
| **身体** | 腿脚、四肢 | 躯干、腹腔 | 五脏六腑、胸腔 | 头面、生殖、排泄 |
| **用物** | 鞋、别人之物 | 祖产、学业、单位 | **房子、卧室、私产** | **车、门、衣帽、进出钱物** |
| **财富上限** | 起步千万、可上亿 | 千万、搞好上亿 | 百万、千万 | 十万、百万 |
| **官位上限** | 省部级 | 厅级 | 处级 | 科级 |
| **主宾** | 宾（别人） | 宾 | 主 | 主（问家庭时） |

| 柱位四读 | 规则 |
|---|---|
| 远近 | 年时为远、坐下为近；两宫**相克＝远（跨省）、相生＝近（同城）** |
| 先后 | 时限理论：年 → 月 → 日 → 时排两件事的先后 |
| 大小 | 年 ＞ 月 ＞ 日 ＞ 时（**大 ≠ 是你的**） |
| 限运 | 各管一段；应期次序：**大限 → 大运 → 流年** |

| 主宾切法 | 问什么 |
|---|---|
| 日干为主 | 能力、性格、想法 |
| 日柱为主 | 婚姻 |
| 日时为主 | 家庭、子女、晚年 |
| 月日为主 | 本地外地、近处远处 |

| 三套阴阳 | 用途 |
|---|---|
| 寅至未阳、申至丑阴 | **断事取象**（木火文科、金水理科） |
| 子寅辰午申戌阳 | **查神煞** |
| 寅申巳亥辰戌阳 | **定十神**（天地阴阳诀） |

**六亲通则**：「宫为主，星为辅；宫星同坏，六亲遭殃」｜**宫位定上限，做功定实得**｜天干主外在之象，地支主内在实质。
